# 數學勇者美術資產規格

## 女生勇者

- 身分參照：`references/hero-female-style-reference-v1.png`
- 風格：16-bit 像素風、硬邊像素塊、有限色盤、透明背景
- 固定特徵：深棕高馬尾、藍綠短披風、藍／青綠／金／米白輕甲、右向持劍
- 單幀尺寸：`128×128`
- 朝向：右
- 角色視覺中心：`x = 64`
- 腳底基準線：`y = 112`
- 本體高度：鞋底至髮頂約 `84 px`；所有動畫維持同一身體與頭身比例
- 安全邊距：四邊至少 `8 px`
- 最大內容範圍：`x = 8..119`、`y = 8..119`；身體、頭髮、披風、劍、陰影與特效都不得超出

### `hero-idle-v1`

- 用途：戰鬥待機循環
- 幀數與順序：4 幀，`idle-01`、`idle-02`、`idle-03`、`idle-04`；第 4 幀精確複用第 2 幀，循環為 `1 → 2 → 3 → 2`
- 圖集排列：1 列 × 4 欄，總尺寸 `512×128`
- 動作：呼吸與披風／馬尾的極小幅度擺動；雙腳位置與腳底基準線固定
- 禁止：跨格、碰觸格線、角色縮放、改變臉型／服裝、移動站位、加入發光或粒子

### `hero-attack-v1`

- 用途：答對時的單次揮劍攻擊
- 幀數與順序：4 幀，`attack-01` 預備、`attack-02` 起揮、`attack-03` 命中、`attack-04` 收勢
- 圖集排列：1 列 × 4 欄，總尺寸 `512×128`
- 單幀與基準：沿用勇者 `128×128`、右向、`x = 64` 視覺中心及 `y = 112` 腳底基準線
- 動作：身體可在格內向右壓低與跨步，但角色比例不變；最後一幀回到可銜接待機的姿勢
- 劍光：只在命中幀出現一段青白色短弧，須完整位於 `x = 8..119`、`y = 8..119`
- 禁止：跨格、碰觸格線、改變角色身份／服裝／劍、把攻擊弧延伸到相鄰幀、以裁切隱藏越界

### `hero-hurt-v1`

- 用途：勇者承受敵人攻擊或錯答反擊
- 幀數與順序：3 幀，`hurt-01` 命中、`hurt-02` 後仰、`hurt-03` 重新站穩
- 圖集排列：1 列 × 3 欄，總尺寸 `384×128`
- 單幀與基準：沿用勇者 `128×128`、右向、`x = 64` 視覺中心及 `y = 112` 腳底基準線
- 動作：劍不脫手；角色可在格內向左後仰，最後一幀回到能銜接待機的防守姿勢
- 命中特效：只在第 1 幀使用一枚貼近右肩／護甲的短小橙白像素星芒，完整位於安全範圍內
- 禁止：血液、傷口、恐怖表情、倒地、跨格、碰觸格線、角色縮放、把紅色受傷 tint 烤進圖片

### `hero-victory-v1`

- 用途：第五關勝利後與獎勵轉盤前的短暫慶祝
- 幀數與順序：4 幀，`victory-01` 確認勝利、`victory-02` 舉劍、`victory-03` 星光定格、`victory-04`；第 4 幀精確複用第 3 幀
- 圖集排列：1 列 × 4 欄，總尺寸 `512×128`
- 單幀與基準：沿用勇者 `128×128`、右向、`x = 64` 視覺中心及 `y = 112` 腳底基準線
- 動作：從待機站姿轉為笑著舉劍，雙腳保持地面基準；最後定格後由結算 UI 接手
- 星光：只在第 3～4 幀使用三枚以內的金白色小星光，貼近劍尖與肩膀，全部位於安全範圍內
- 禁止：紙花、文字、獎勵圖示、跨格、碰觸格線、角色縮放、讓星光散落到相鄰幀

### `hero-defeat-v1`

- 用途：HP 歸零後進入「再戰本關」結算
- 幀數與順序：4 幀，`defeat-01` 失去平衡、`defeat-02` 單膝跪地、`defeat-03` 坐倒仍握劍、`defeat-04`；第 4 幀精確複用第 3 幀
- 圖集排列：1 列 × 4 欄，總尺寸 `512×128`
- 單幀與基準：沿用勇者 `128×128`、右向與既有角色比例；站立幀腳底維持 `y = 112`，跪坐幀以同一地面線承載最低接觸點
- 動作：呈現暫時力竭而非死亡；劍始終握在手中或靠在身旁，最後仍保持清醒
- 禁止：血液、傷口、昏迷眼、死亡暗示、武器飛出、跨格、碰觸格線、角色縮放

### `hero-restore-v1`

- 用途：過關回血、選擇成長卡後恢復，以及本關再戰回滿 HP
- 幀數與順序：3 幀，`restore-01` 能量亮起、`restore-02` 挺身恢復、`restore-03`；第 3 幀精確複用 `hero-idle-v1` 的第 1 幀
- 圖集排列：1 列 × 3 欄，總尺寸 `384×128`
- 單幀與基準：沿用勇者 `128×128`、右向、`x = 64` 視覺中心及 `y = 112` 腳底基準線
- 特效：青綠與金白色的短光環／小光點緊貼身體，完整位於安全範圍內；不得遮住臉與武器
- 禁止：大型光柱、文字、卡牌圖示、跨格、碰觸格線、角色縮放或改變裝備

## 第一關敵人

- 身分參照：`references/stage-1-enemies-style-reference-v2.png`
- 風格：與女生勇者一致的 16-bit 像素風、硬邊像素塊、有限色盤、透明背景
- 單幀尺寸：`128×128`；每個動作皆為 1 列 × 3 欄，圖集總尺寸 `384×128`
- 朝向：左
- 地面基準線：`y = 109`
- 安全邊距：四邊至少 `8 px`
- 最大內容範圍：`x = 8..119`、`y = 8..119`；本體、木棒、飛濺、星芒與動作線都不得超出
- 果凍史萊姆：青藍圓胖膠質身體、固定臉型與高光；待機本體約高 `62 px`、寬 `97 px`，底部中心錨點 `x = 64`
- 木棒哥布林：綠皮、大耳、單顆小牙、紅橙圍巾、棕色皮甲與木棒；待機本體含耳約高 `82 px`，雙腳中心錨點 `x = 68`
- 共用動作：`idle` 待機、`charge` 蓄力預警、`attack` 出手、`hurt` 受擊、`defeat` 敗退；每種皆為 3 幀

### 第一關敵人動作順序

- `idle`：中立、輕微壓縮、回彈；循環播放，位置與比例不變
- `charge`：開始蓄力、蓄力增強、準備出手；只允許貼近本體的橙黃色短像素提示，不使用大型光圈
- `attack`：預備、命中、收勢；史萊姆在格內向左彈撞，哥布林在格內向左揮棒
- `hurt`：命中、向右退縮、重新穩住；第 1 幀只使用貼近本體的小型橙白星芒
- `defeat`：失衡、倒下、力竭定格；呈現被打敗而非死亡，保持清醒且不使用血液、傷口或昏迷眼
- 禁止：跨格、碰觸格線、逐幀縮放、身份漂移、武器或特效進入相鄰格、個別自動裁切
- 哥布林蓄力採用 `goblin-charge-v3`；木棒由胸前沿身體前方抬起，兩條手臂分居棒柄兩側、手腕不交叉，最後在額頭前上方雙手高舉準備下砸

## 第二關敵人

- 身分參照：`references/stage-2-enemies-style-reference-v2.png`
- 風格：沿用既有 16-bit 硬邊像素風、有限色盤與透明背景，危險感高於第一關
- 單幀尺寸：`128×128`；每個動作皆為 1 列 × 3 欄，圖集總尺寸 `384×128`
- 朝向：左；安全邊距四邊至少 `8 px`；最大內容範圍 `x = 8..119`、`y = 8..119`
- 毒牙蝙蝠：飛行中心錨點 `x = 64`、`y = 64`；固定深藍紫配色、短獠牙、兩翼與兩足，翼展、爪與毒效皆不得越界
- 荊棘魔菇：根足地面基準線 `y = 109`、中心錨點 `x = 64`；固定暗紅刺帽、米棕菌柄、兩條藤臂與兩隻根足
- 共用動作：`idle` 待機、`charge` 蓄力預警、`attack` 出手、`hurt` 受擊、`defeat` 敗退；每種皆為 3 幀
- `idle`：中立、輕微收縮、回彈；蝙蝠拍翼，魔菇呼吸與藤臂微動
- `charge`：開始蓄力、蓄力增強、準備出手；只允許貼近本體的少量紫色或橙黃色像素提示
- `attack`：預備、命中、收勢；蝙蝠向左俯衝咬擊，魔菇以左側藤拳重擊
- `hurt`：命中、向右退縮、重新穩住；第 1 幀只使用貼近本體的小型橙白星芒
- `defeat`：失衡、落下／跪倒、力竭定格；保持清醒，不使用血液、傷口或死亡暗示
- 禁止：跨格、碰觸格線、逐幀縮放、身份漂移、翅膀／藤蔓／刺／特效進入相鄰格、個別自動裁切

## 第三關敵人

- 身分參照：`references/stage-3-enemies-style-reference-v1.png`
- 單幀 `128×128`；每動作 3 幀、1 列 × 3 欄，圖集 `384×128`；朝左；四邊至少 `8 px`
- 雷紋蜥蜴：兩臂、兩腿、單一緊湊尾巴，固定藍青雷紋；地面基準線 `y = 109`、中心 `x = 64`
- 鐵甲魔獸：四足、單一短角、固定鐵甲片與紅色披掛；地面基準線 `y = 109`、中心 `x = 64`
- 共用 `idle`、`charge`、`attack`、`hurt`、`defeat`，每種 3 幀；蓄力與命中特效須貼近本體
- 雷紋蜥蜴以低伏、蓄電、向左爪擊／撲擊呈現速度；不得生成離體雷球或加長尾巴
- 鐵甲魔獸以踏地、低頭蓄力、向左短距衝撞呈現重量；不得增減腿、角、裝甲或讓披掛跨格
- 敗退皆保持清醒且非死亡；禁止血液、傷口、跨格、碰線、逐幀縮放、身份漂移與個別自動裁切

## 第四關敵人

- 身分參照：`references/stage-4-enemies-style-reference-v1.png`
- 單幀 `128×128`；每動作 3 幀，圖集 `384×128`；朝左；四邊至少 `8 px`；地面線 `y = 109`

- 敗退保持清醒且非死亡；禁止血液、傷口、跨格、碰線、逐幀縮放、身份漂移與個別自動裁切

## 第五關敵人／最終王

- 身分參照：`references/stage-5-bosses-style-reference-v1.png`
- 單幀 `128×128`；每動作 3 幀，圖集 `384×128`；朝左；四邊至少 `8 px`；地面線 `y = 109`
- 暴風魔龍：翼足型龍體，固定一顆頭、兩翼兼前肢、兩條後腿與一條貼近身體的短捲尾；深藍鱗片、銀灰胸甲、青色雷紋與短後掠角，不得額外生成前腿或離體雷電
- 虛空魔王：固定一顆角冠頭盔、一個軀幹、兩臂、兩腿與胸甲上的單一虛空核心；黑紫王者重甲、短破披肩、洋紅裂紋與巨型爪手，不使用武器、翅膀或尾巴
- 兩者維持最終關壓迫感；魔王略高、魔龍略寬，但動畫期間不得逐幀改變本體比例
- 共用 `idle`、`charge`、`attack`、`hurt`、`defeat`，每種 3 幀；翼、尾、披肩、角、爪與所有雷光／虛空效果皆須貼近本體
- 敗退保持清醒且非死亡；禁止血液、傷口、跨格、碰線、身份漂移、增減肢體與個別自動裁切

## 戰鬥基本特效

- 風格參照：`references/battle-effects-style-reference-v1.png`
- 每個特效單幀 `128×128`，動畫 3 幀、1 列 × 3 欄，圖集 `384×128`；透明背景
- 固定中心錨點 `x = 64`、`y = 64`；四邊至少 `8 px`，最大內容範圍 `x = 8..119`、`y = 8..119`
- 動畫順序固定為「出現／聚集、最大強度、消散／收束」；不得逐幀改變裁切或以放大造成碰線
- 共十種：`sword-slash` 勇者劍擊、`hit-spark` 共用命中、`enemy-impact` 敵人重擊、`correct-burst` 答對、`wrong-warning` 答錯預警、`heal-ring` 治療、`guard-flash` 護盾／減傷、`charge-aura` 蓄力、`storm-lightning` 雷電、`void-slash` 虛空斬擊
- 共用特效保持中性且清楚；雷電與虛空為第五關專用色彩。禁止人物、怪物、武器實體、文字、數字、UI、跨格、碰線、過量散落粒子及個別自動裁切
