# 美術速查

## 數學勇者

硬邊 cel shading、粗深色描邊、低彩度；怪物遮臉／頭盔／骨骼、冷光眼，金飾由小兵到魔王逐步增加。避免柔霧和過度可愛表情。
勇者朝右、怪物朝左，目光朝對手；怪物的布料／拖尾朝右後方。姿勢用明確幾何位置描述，動作幀共享站姿比例。

角色透明 WebP；場景不去背。腳本沿用原輸出規格，換圖以現行 React 戰場實際疊圖驗收，勿沿用舊 CSS 的角色位置假設。

## 製作工具

- scripts/math-rpg-keyer.ps1：-SourceDirectory 指定原 PNG，-OutputDirectory 指定去背輸出；預設輸出 .art-output/keyed。
- scripts/math-rpg-fx.sh、math-rpg-stages.sh：先設定 SRC 來源目錄，需要 Bash／ffmpeg；執行會更新對應 WebP，修改前確認來源與輸出。
- 角色用洋紅底 HSV 去背，攻擊幀鎖定站姿比例；發光特效用黑底，alpha=max(R,G,B)，不以硬門檻截斷光暈。
- 保留角色完整輪廓；背景避免在角色範圍放柱子／樹幹／強光。用不同寬高視窗檢查地面、白色劍氣與明暗對比。
- 舊完整生成提示詞可查 Git 歷史；概念 PNG 保留於原始碼，不發布。

## 其他遊戲

- 班級圖集 char1.webp 為 Mana Seed 512×512，8×8 格、每格 64px；方向 down/up/right/left，站姿上半第 0 欄，走路下半 0～5 欄，跑步 0,1,6,3,4,7；保持 nearest 取樣。
- 偵探每案使用獨立資料夾，向量 props 可替換成圖片而不改熱點；座標基準見 [偵探指南](../../../docs/detective-authoring.md)。
