## 數學勇者 · 六隻怪

`ENEMY_LOOKS` 與 `ENEMY_TRAITS` **索引對齊**（`assets/js/math-rpg.js`），
改一邊就要改另一邊。

| # | 名稱 | Emoji | 圖 | 待機 | 特性 |
|---|---|---|---|---|---|
| 1 | 暗影小獸 | 🐾 | enemy1.webp | 站立呼吸 | **無** — 教學關，刻意什麼都沒有 |
| 2 | 骨翼渡鴉 | 🪶 | enemy2.webp | `float` 飄浮 | 撕裂：每 3 次攻擊改施 3 層流血 |
| 3 | 提燈幽魂 | 🏮 | enemy3.webp | `float` 飄浮 | 迷霧：每 3 次攻擊改施 2 層迷霧 |
| 4 | 骨龍 | 🦴 | enemy4.webp | 站立呼吸 | 灼燒：每 **2** 次攻擊改施 4 層流血 |
| 5 | 黑騎士 | ⚔️ | enemy5.webp | `heavy` 重量感 | 重甲：`armor: 12` |
| 6 | 暗黑魔王 | 👑 | enemy6.webp | `heavy` 重量感 | 暗影爪（每 3 次 3 層流血）＋ **狂暴**：半血後攻擊 ×1.5 且每擊附 2 層流血 |

搭配的數值（刀數 / 攻擊力）見 [COMBAT.md](COMBAT.md)。

### 特性的設計意圖

六隻怪**不是只有血量不同**，每一隻換一種壓力來源：

- **1 暗影小獸** — 空白是刻意的。先讓孩子熟悉「答對→攻擊、答錯→挨打」的基本循環，
  再開始加變數
- **2 骨翼渡鴉** — 第一次遇到流血，層數給少（3 層）當作教學劑量
- **3 提燈幽魂** — **不碰傷害，只壓縮思考時間**。壓力換一種，對算得慢的孩子最有感，
  所以只給這一隻，而且有 8 秒下限保護
- **4 骨龍** — 流血的強化版，觸發也更頻繁（每 2 次）
- **5 黑騎士** — **敵人也有護甲，跟勇者是同一個機制**。狀態列上看得到 🛡️12，
  孩子從對面身上學會這個數字的意義
- **6 暗黑魔王** — 狂暴，第一次出現「戰鬥中途難度會變」

### 資料欄位

```js
// ENEMY_TRAITS
{
  special: { every: N, name: '招式名', bleed: N, fog: N },  // null = 普通怪
  armor: N,                                                 // 每次受擊直接減免
  enrage: { at: 0.5, atkMult: 1.5, bleed: N }               // 血量低於 at 時觸發
}

// ENEMY_LOOKS
{ emoji, name, img, idle }   // idle 省略 = 站立呼吸；"float" / "heavy"
```

**`armor` 會影響刀數**，所以 `spawnEnemy()` 是用「扣掉護甲後的有效傷害」回推血量的 ——
黑騎士不會因為有護甲就變得比表定更耐打。動 `armor` 就要確認這段還對。

`img` 是後補的插槽：填了就自動改用圖片、不再顯示 emoji，**動畫完全不用改**。
六隻怪目前都還沒有攻擊圖（`atkFrames` 只有勇者有）。

## 偵探事件簿 · 嫌疑人

偵探沒有戰鬥，但有「對手」—— 嫌疑人。機制上他們不是敵人物件，是**資料 ＋ 謎題**：

- **黃金貓頭鷹**：五位嫌疑人以黑板上的證詞紀錄表呈現（UI03A~E），
  用 `deduce` 邏輯矩陣排除
- **AI 展覽館**：`interrogate` 全息審訊 —— 讀證詞、點可疑字詞追問、
  露出破綻才能出示物證，三段防線（鎮定／動搖／崩潰）

**誤判有代價**：`misjudgeLimit` 到達後強制結案，不能無限重試。
結局依誤判次數與「洗清了幾個無辜者」分岔（AI 展覽館有五個結局）。

`accuseMinClues` 控制指認面板的開啟門檻，**必須跟 `refreshHud()` 裡
`accuseBtn.setLocked()` 的判斷同步**，否則按鈕會一直是灰的。
