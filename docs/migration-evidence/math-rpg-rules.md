# 數學勇者純規則基準 · 2026-09-17

目前已建立純規則與回合時間線對照，不代表排程控制器或 React 畫面已完成。

## 已抽離

src/games/math-rpg/questions.ts：兩個年級、九组固定題庫（36 題）及動態除法產生器。createQuestionPools 接收獨立亂數來源，不修改題幹、答案、選項或亂數消耗順序。

src/games/math-rpg/model.ts：初始狀態、六關數值／特性、連擊、護甲、爆擊傷害、流血傷害、迷霧時限、跨關初始化、八張強化與加權三選一。applyUpgrade 回傳新狀態，卡片達上限即退出卡池。尚不排程動畫、不觸發 DOM 或 Pixi。

測試直接讀取舊原始碼的宣告及純規則函式，在隔離 VM 中執行，不另抄一份期望值演算法。

- 六關、6 種連擊、4 種護甲組合，對照一般／爆擊傷害、狂暴、流血與迷霧。
- 跨關清除敵人攻擊次數與負面狀態，但保留玩家生命、護盾及連擊。
- 100 組亂數種子，每組連續五轮加權選卡與套用，卡片 metadata、結果及取滿排除均對照原版。
- 固定 36 題逐欄一致；連續 1,000 題動態除法的題幹、選項、正解索引逐題一致。
- `pnpm test`：21 項 Node + 54 項 Vitest 全過。`pnpm build`：型別及旧站逐檔相容檢查通過。

## 回合時間線（第二批）

src/games/math-rpg/turn.ts 的 resolveTurn 回傳 immediate 及帶毫秒 offset、cue、獨立狀態快照的 events。它只描述一個已鎖定回合，不自行執行計時器；呼叫端必須在重玩或離場時丟棄舊計畫，且在終點前防止重複作答。

測試直接在隔離 VM 執行現行 checkAnswer、damagePlayer、tickStatuses，替換 DOM／視覺副作用並以虛擬時鐘執行 setTimeout。六關 × 三種作答 × 24 組狀態共 432 案，對照即時及每個事件時間的狀態、勝敗／選卡／下一題終點；另有 20 組種子連續作答至勝敗，包含原版選卡及換關結果。視覺效果本身與實際排程器未在此測試範圍內。

第二批驗證：21 項 Node + 57 項 Vitest（78 項）及 production build 通過。保留以下原版結算順序：

1. 答對先增加 combo，再判斷每三次連對生成護盾，接著擲爆擊、算傷害、判斷魔王狂暴及擊殺。答錯／超時先清空 combo，再執行敵人攻擊。
2. 敵人攻擊次數先增加，即使護盾擋下仍計次。護盾擋下整次直接傷害與附加狀態，但既有流血仍會結算。
3. tickStatuses 在排程當下擷取流血傷害，回呼執行時才扣血與遞減層數。新附加的流血不增加本題傷害，但可能在本題回呼被遞減；不能改成「先加所有狀態，再算傷害」。
4. 擊殺敵人後直接進入選卡／勝利流程，不再執行該題流血結算；換關清空流血與迷霧。
5. 下一批建立可取消排程器與作答鎖，再把 React HUD／題目和既有兩個 canvas 接到新的狀態。未做瀏覽器、教室實機與 lab performance 驗收。

舊入口及原腳本未改，新模組目前僅供測試與下一批接線，不會增加首頁產物。
