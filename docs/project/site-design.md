# 暮光森林學習驛站｜網站介面

世界與角色沿用 [暮光森林](../world/README.md)，網站是進入學習內容的驛站。原稿與產製規格見 [網站美術](../world/art/site/manifest.json)；網站使用縮小的 WebP，角色原稿仍只在角色圖鑑保存一份。

## 範圍與分工

- 首頁：暮色林間與米洛迎接，書本與星燈本身就是可點選的入口；保留素材下載、學習活動兩個入口，教師入口在頁尾，不載入活動資料、教材、Firebase 或 Pixi。
- 學習活動：以科學器具、魔法書與提燈辨識入口；標題區保留留白，不放複雜場景，保留原本分類及每個入口。
- 教師工具：以羽筆、書本與鑰匙區分上傳、班級管理、偵探驗證碼。表單、登入、權限、驗證碼及儲存契約維持原樣。
- 教材與素材頁：沿用知識內容與圖解，網站外框、導航和操作色票統一；不把科學教材改寫成虛構故事。
- 遊戲：保留遊戲本體、場景、玩法與素材；共用網站識別及瀏覽器頁籤圖示更新。既有案件內的角色屬於遊戲內容，不隨網站品牌清除。

## 視覺與操作

依工坊原稿使用靛紫暮色、梅紫布料、青綠玻璃與少量暖金光；色票集中於 [theme.css](../../assets/css/theme.css) 的 `body.forest-site`，遊戲頁不加此類別。網站共有樣式在 [forest.css](../../src/styles/forest.css)，首頁與功能頁的樣式分開載入。

首頁以少量懸浮星燈、微光小徑與暮色光暈呈現魔法，背景低對比且留白；前景物件清晰飽和。活動與教師入口使用無外框的物件陳列及短標籤，不堆疊長條卡片。操作物件與文字共用可聚焦的語意連結，不增加 Canvas／Pixi 載入。功能表單保留明確邊界與可閱讀的實色表面。文字統一使用系統無襯線字體，不增加遠端字型請求。

操作回饋以選中物件輕微抬起與柔光陰影為主，沒有跟隨游標的粒子、滾動綁架、背景音樂或延遲開啟的入口。減少動態偏好直接停用裝飾動畫，鍵盤焦點與觸控命中範圍保留；明／暗／系統主題均可使用。

## 維護與驗收

圖片規格和尺寸由 [prepare-site-art.py](../../scripts/prepare-site-art.py) 與 [輸出清單](../world/art/site/display-manifest.json) 管理。首屏背景有手機尺寸，其他物件延後載入；首頁維持獨立的 JS／CSS 體積限制。驗收須涵蓋窄螢幕、不溢位、圖檔載入、明暗主題、鍵盤、減少動態及教師登入／表單狀態。測試用資料不得混入真實學生、帳號或有效驗證碼。
