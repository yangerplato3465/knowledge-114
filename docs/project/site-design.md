# 暮光森林學習驛站｜網站介面

世界與角色沿用 [暮光森林](../world/README.md)，網站是進入學習內容的驛站。原稿與產製規格見 [網站美術](../world/art/site/manifest.json)；網站使用縮小的 WebP，角色原稿仍只在角色圖鑑保存一份。

## 範圍與分工

- 首頁：暮色林間與米洛迎接，書本與星燈本身就是可點選的入口；保留素材下載、學習活動兩個入口，教師入口在頁尾，不載入活動資料、教材、Firebase 或 Pixi。米洛在標題下方的專屬區域散步、說話與施展小魔法，不覆蓋文字或入口；使用者可點她切換動作。
- 學習活動：以一張完整的星燈星圖呈現觀察座、冒險座與線索座；標題與圖案分開，選中星座後放大畫面，再顯示有名稱的活動簿與原本每個入口。活動簿用來選擇活動，唯一的進入連結位於旁邊的活動介紹。星圖是活動索引，不代表暮光森林地理。
- 教師工具：以羽筆、書本與鑰匙區分上傳、班級管理、偵探驗證碼。表單、登入、權限、驗證碼及儲存契約維持原樣。
- 教材與素材頁：沿用知識內容與圖解，網站外框、導航和操作色票統一；不把科學教材改寫成虛構故事。
- 遊戲：場景使用各自色票；偵探頁面外框沿用網站入口配色。數學勇者沿用魔法工坊的網站導覽、主題切換、返回列與等寬遊戲外框；框內以 Pixi 呈現上古封面、角色微動、單元選關及像素答題戰鬥，遊戲按鈕和全螢幕操作也在框內。既有案件內的角色屬於遊戲內容，不隨網站品牌清除。

## 視覺與操作

依工坊原稿使用靛紫暮色、梅紫布料、青綠玻璃與少量暖金光；網站色票集中於 [theme.css](../../assets/css/theme.css) 的 `body.forest-site`，遊戲頁不加此類別。偵探等遊戲頁面外框使用 [forest-game-frame.css](../../src/styles/forest-game-frame.css) 的獨立色票，數學勇者的核准封面採暮光、青綠與靛紫的遊戲色票。網站共有樣式在 [forest.css](../../src/styles/forest.css)，首頁與功能頁的樣式分開載入。

首頁以少量懸浮星燈、微光小徑與暮色光暈呈現魔法，背景低對比且留白；前景物件清晰飽和。活動星圖在一幅美術圖中畫出三個可辨識的星座輪廓作為大面積入口，名稱由可聚焦的按鈕標示；星座內的活動簿顯示名稱並切換旁側介紹，不靠猜星點。學習活動與各遊戲入口共用網站頁首，遊戲專屬狀態放在次層。教師入口維持帶淡金紙框的物件陳列。功能表單保留明確邊界與可閱讀的實色表面。文字統一使用系統無襯線字體，不增加遠端字型請求。

操作回饋以選中物件輕微抬起與柔光陰影為主；活動星座點選後以短暫放大導入內容，減少動態偏好時直接切換。沒有跟隨游標的粒子、滾動綁架或背景音樂。米洛的對話不自動朗讀；頁面在背景時暫停她的動作計時，減少動態偏好下不自動播放，仍可手動切換對話。鍵盤焦點與觸控命中範圍保留；共用主題開關只切換明暗。

## 入口版面重點

- **美術服務辨識**：首頁以暮色森林和可點選的書本、星燈引路；學習活動用一幅完整星圖呈現三座不同輪廓的星座，名稱留在圖形之外。活動增加時，先按星座分類，再以具名活動簿尋找，不要求使用者辨認單顆星。
- **選擇後立即看見出口**：從被點選的星座位置放大，進入該座的觀測圖與活動簿；點活動會切換旁側介紹，並將唯一的紫色進入連結帶到可見位置，不另開彈窗。返回連結帶回原星座。
- **外框與內容對齊**：各入口共用網站頁首，返回列與主要內容沿用同一版心（見 [activity-trail.css](../../src/styles/activity-trail.css)）；遊戲以圓角框包住場景。畫面比例改變時延伸場景背景，避免裁切後露出突兀色塊；網站外框的紫金色票不覆蓋遊戲內的美術。
- **依裝置安排操作**：工坊的全螢幕控制放在遊戲內。偵探案件在手機直向持機時直接橫放畫面並同步觸控座標；手機遊戲內顯示「回線索座」，桌機使用頁面返回列。窄螢幕仍須保留可見入口與足夠觸控範圍。

## 維護與驗收

圖片規格和尺寸由 [prepare-site-art.py](../../scripts/prepare-site-art.py) 與 [輸出清單](../world/art/site/display-manifest.json) 管理。首屏背景有手機尺寸，其他物件延後載入；首頁維持獨立的 JS／CSS 體積限制。驗收須涵蓋窄螢幕、不溢位、圖檔載入、明暗主題、鍵盤、減少動態及教師登入／表單狀態。測試用資料不得混入真實學生、帳號或有效驗證碼。
