# 偵探遊戲：星燈小徑燈光偏移事件

## 定位與範圍

第二款偵探遊戲的設計與實作依據。黃金貓頭鷹案維持現況；本案保留第一案「走進現場、查看物件、收集線索、解謎、比對說法、整理真相」的熟悉節奏，改以事件順序與路線重建作為新的推理核心。實際題目、時刻與解答以 [`starlight.js`](../../../assets/js/detective/cases/starlight.js) 和 [`starlight-rules.js`](../../../assets/js/detective/starlight-rules.js) 為準。

本案接續 [暮光森林世界觀](../../world/README.md)，人物辨識與原圖以 [角色圖鑑](../../world/characters.md) 為準。米洛仍是陪伴主角；開場以十二幀逐步換上短斗篷、筆記包與放大鏡，維持原本臉部、髮型與身形，每幀只有一套完整造型。進入調查後，對話卷軸旁的小頭像沿用偵探造型定稿幀，點頭像仍可求提示，避免大立繪遮住場景。可以新增居民，需有清楚的生活職責、個性及與既有居民的關係。

## 六項開工要點

### 一句話委託

諾爾發現星燈小徑的燈光指引圖樣偏離了原本路線，晚歸居民因此走錯岔路；米洛受託查明昨夜哪些燈被調整、為何改變方向，讓旅人和夜行小動物都能安心通行。

### 學習與推理目標

玩家從現場痕跡、居民證詞和燈具紀錄重建「誰在何時做了什麼」，再以事件先後與空間線索解釋錯誤路線如何形成。核心能力是觀察、時間順序、線索交叉比對和因果推理；結案前須能用多項獨立線索支持解釋，不能只靠單一證詞或猜人。

### 核心操作與規則

沿用點擊調查、可重讀線索、對話提示與場景移動。十件實物先從場景取下，再從物品欄選取，實際用在相應的現場；謎題不再只查「已收集」。選中物件會指出可用場所並框出當前場景的用途位置，觸控與鍵盤也能以點選完成。已用過的物件留在欄位供回看，信封須先核時、再核郵路。安排五個短謎題，由現場物件逐步帶出事件全貌；每題解答都提供下一步可用的事實。

1. **重排巡燈紀錄**：把散落的巡查地點與時間記錄放回守燈亭的值勤板，找出燈光最後一次方向正常及最早確定偏移的時間，縮小燈罩被調整的時段。
2. **比對調整痕跡**：帶回小徑燈柱的刮痕卡榫、守燈亭桌前的備用燈罩、夜花坡的折布與花粉瓶，比對小徑的三盞燈。解答指出哪些燈被動過；花粉只說明物件曾接近夜花，不單獨用來判定是誰做的。
3. **重現燈光方向**：在現場縮圖轉動第二、三盞燈的遮光罩，比較主路舊標記和夜花旁的弱光，重現昨夜偏向岔路的光痕。玩家確認改變方向的是遮光罩而非星燈本身。
4. **解開郵路封緘**：將平石拓片、停用印記與退信放到石橋長椅的郵袋旁。三環圖形鎖按照「岔口起點、途中地標、舊郵箱」讀取，玩家須把星形路標、石橋拱形與榛枝印記連到實際地形；開袋後才能取得投遞單，核對奧利經過第二、三盞燈與錯投郵箱的先後。這個暗碼來自本案路線，不使用無關數字。
5. **拼回事件順序**：把「夜蛾聚集、燈罩調整、旅人看見偏移光斑、郵件走錯岔路」等事件卡排成因果鏈，再指出仍需向哪位居民確認動機。這是證據整理，不是只靠猜人名的指認題。

### 劇情節奏與懸念設計

設計文件先列出完整真相供製作推理鏈使用；遊戲中的角色台詞和線索則依下列順序揭露，開場與前段不得直接說出「夜蛾照護員調整燈罩」或「為了保護夜蛾」。

| 段落 | 玩家目前知道的事 | 新線索／謎題帶來的變化 |
| --- | --- | --- |
| **起：不合理的歸途** | 星燈全都亮著，奧利卻把信送到「舊榛樹郵箱」；那條郵路早已停用。諾爾確認燈沒有熄滅，只是光照向不熟悉的方向。 | 玩家先調查信封、路標和星燈。疑問是「路沒有消失，為什麼大家都走錯了？」舊郵路印記也讓人猜想奧利是不是自行改了路線。 |
| **承：時間對不上** | 有人記得燈光照著路標，有人卻說那時光已偏向岔路；巡燈值勤板只記著巡查時間與地點，沒有記下每盞燈的角度。 | 謎題一重排值勤紀錄，確認最後正常及最早偏移的時間，圈出燈罩被調整的時段。石橋的投遞單稍後能解開目擊時間看似衝突的原因。 |
| **承：不是風吹歪的** | 燈罩卡榫有新刮痕，附近留有遮光布纖維和夜花花粉。痕跡像是有人動過，但仍不能由花粉或工具推斷是誰。 | 謎題二配對現場痕跡，將調查方向從天候故障轉為「有人調整了燈罩」。玩家會自然考慮是否有人故意把旅人引離道路。 |
| **轉：光不是指向藏匿處** | 調整後的燈光沒有照向屋舍或財物，反而落在路旁一小片夜花上；花叢裡有剛孵化的夜蛾。 | 謎題三重現燈罩方向，讓玩家看見光束原本被遮暗、並沿花叢上方形成一條低光帶。這表示調整可能是為了引導夜蛾避開強光，並非為了把人帶錯路。動機仍未證實。 |
| **轉：看似矛盾的證詞** | 奧利說自己沒有選擇舊郵路，另一位居民卻看見郵袋經過第三盞燈附近；舊路印記看起來像是他有意繞路。 | 謎題四以三件實物辨讀地標暗碼，打開封緘郵袋，取得投遞單；印記與時間還原他跟著偏移光線進入舊路。兩人都沒有說謊。 |
| **合：誰做了、為什麼** | 玩家已知有人調整燈罩、調整發生的時間、受影響的路線，以及光線如何照顧夜蛾；還欠下最後的行動者和動機確認。 | 謎題五把行動者、時間、調整方式、光線結果與仍待確認的問題排成事件鏈。夜蛾照護員承認自己調整燈罩，說明原本只想讓夜蛾避開強光，沒有察覺低光帶會讓旅人把岔路看成回家方向。 |
| **收：一起修好路** | 事實已確認，沒有惡意犯人，但好意造成了真實的不便。 | 米洛、諾爾、奧利與照護員重新安排燈罩：保留夜蛾需要的柔暗區，在岔路加上不刺眼的地面路標。歸還的信送抵收件人，所有人都知道以後如何辨認新路線。 |

**完整真相（設計者用）**：夜蛾照護員芮雅為替剛孵化的夜蛾避開強光，調整了第二、三盞燈的遮光罩；她沒有察覺主路的舊地面標記因此變暗，弱光又沿岔路邊緣形成可誤認的低光帶。她的動機出於照顧而非惡意。調查先證明燈罩、光線與郵路的因果，再向芮雅確認動機。

各步驟的完整台詞和答案只維護在[案件腳本](../../../assets/js/detective/cases/starlight.js)與[謎題模組](../../../assets/js/detective/starlight-puzzles.js)；表格只記玩家必須親手做出的因果動作。

開場文字方向：

> 「這盞燈明明亮著，為什麼信會走到舊榛樹那裡？」奧利把退回的信放到桌上。信封上的投遞印記，已經很久沒在正式郵路上出現了。
>
> 諾爾望向小徑：「昨晚沒有一盞燈熄掉。只是……光落下來的地方，和以前不一樣。」

首次進入且沒有可恢復進度時，開場先用小徑、石橋舊郵路與守燈亭三個既有場景演出：奧利在岔路中央左右張望，背向玩家沿右側彎曲的光帶走去，在乾燥路面盡頭前轉場；在石橋場景由畫面右下角的道路進場，轉向左上方的舊郵箱，看到錯投後錯愕；接著跑向守燈亭向諾爾求助，諾爾也困惑。米洛慢步加入，停下與兩人對望，再讓星光環繞，以十二幀逐步換上偵探裝束，最後回到既有案件介紹。每段移動使用符合路徑的角色方位；圖片預先載入，切景交疊淡入。同框比例遵循[共用角色尺度](../../world/characters.md#同場角色尺度)，換姿勢以可見輪廓或固定身體尺度校準。回復存檔直接進現場，動畫可略過；系統偏好減少動態時直接顯示案件介紹。格位、安全邊界及加工方式見[開場素材清單](../../world/art/manifests/starlight-opening-manifest.json)。

開場右上角提供簡短的「跳過動畫」與全螢幕切換。調查畫面的出口標示和點擊熱區放在道路可見的岔口或沿路燈柱旁，以斜箭頭提示行進方向，不在路面疊大型獨立按鈕。對話卷軸置中，文字依行數在紙面垂直置中；同一用途的文字固定字型與字級，重點靠句子與情境表達，不靠單字深淺。木牌與進度文字連同箭頭一起置中。

變裝以相鄰兩張關鍵姿勢為基礎，在 WebGL 上用 shader 讓星光接縫自上而下掃過角色，逐區顯示新造型並加入輕微布料波動；同一位置不疊放新舊帽子。各幀以臉部中心定位，腳部另作局部校正，並從偵探定稿幀取用一致的五官與臉型，避免換裝時整個角色橫移或臉部忽然變形。其他渲染後端沿用相同十二幀與臉部定位、星光特效，案件操作不受影響。

轉折後的對話方向：

> 夜蛾照護員低頭看著收起來的遮光布：「我只想讓牠們不要被亮光嚇到。我不知道那道柔光會讓人看錯岔路。」
>
> 米洛把筆記本合上：「現在我們知道光去了哪裡。接下來，一起替旅人和夜蛾都留一條安全的路吧。」

無效操作不扣分、不耗盡線索，也不造成角色受罰。重排錯誤時可復原或再試；分層提示先提醒觀察方向，再協助比對線索，不直接代填答案。指認流程改為提出「事件解釋／需要再確認的線索」，避免把未證實猜測寫成對居民的定罪。

### 場景與介面草圖

主畫面是可探索的暮光森林夜間場所，不使用網頁卡片或表單拼成遊玩區。現有四個 Pixi 場景：星燈小徑的左右岔路分別通往夜花坡、石橋舊郵路，另可前往諾爾的守燈亭。兩條支路的夜蛾與郵路線索都須取得，才能整理最終事件。視覺沿用魔法工坊的靛紫暮色、暖木牌、羊皮紙與米洛立繪；文字依卷宗、線索卡和對話卷軸的安全區排版，避免碰到裝飾框。

- 路標、燈柱、值勤板、郵件、燈罩、布簾、夜花、舊郵箱與橋頭平石都能直接調查。四個場景背景已分別清掉可取走物件的原有痕跡，保留固定環境物件；獨立圖片落在較簡淨、明暗有別的木面、石面或暗色開口上，拿走後不留複本。守燈亭板上的值勤紙與信封可拿取，路線圖、檢修紙與花況紙各有不同圖案並可點擊調查。
- 十件實物分別出自四處場景，拖進物品欄後仍須選取，再點對應的場景熱點才算使用；信封有兩次用途。物品欄保留八格視窗，超出時可翻頁；已用過的物件有標記且可回看。鍵盤與讀屏提供收納及使用等效操作。拖曳提示用共用手形圖片，線索與放大檢視用共用放大鏡圖片；原稿、尺寸與留白見[案件互動素材清單](../../world/art/manifests/starlight-interactives-manifest.json)。
- 守燈亭中的諾爾沿用開場正視幀與可見身高，點他可依調查進度對話。出口貼合道路方向，木牌正文置中；對玩家無用的場景操作按鈕不常駐在畫面上。
- Pixi 呈現主要可玩場景和物件操作，DOM 提供鍵盤、螢幕閱讀器及可存取的等效操作；觸控與鍵盤可完成核心操作，拖曳提供點選替代。手機使用[共用橫向版](authoring.md#設計與視覺)，直向持機時畫面直接橫放，觸控座標與畫面同步旋轉。
- 米洛服裝可改為夜巡裝束；諾爾沿用角色辨識與個性。新夜蛾照護員可有柔光面紗或收納遮光罩的工具包等職業辨識物，不用神祕化或把外觀當作可疑證據。

### 故事、彩蛋與系列連結

故事由「居民遇到實際困難」開始，以小徑重新照亮、旅人順利回家及照護員找到兼顧小動物的燈光方式收尾。諾爾的安靜細心可前後呼應：開場注意到某盞燈的光落低了，結尾則為怕黑的旅人保留一盞較柔和的夜燈。奧利可因送錯郵件提供時間線索；他的郵袋暗袋偶爾會收住一片迷路的風。

彩蛋藏在可選查看的生活細節和回訪對話，不參與必需答案、不誘導錯誤操作，也不要求重複失敗。例：米洛的記錄包裡夾著工坊的簡短補給清單；某封信被奧利提早送達，收信人因此多留了一盞燈。

本案可開啟「暮光森林偵探筆記」的系列連結：每宗案件結案後，筆記多一枚由委託居民留下的微光印記；印記逐步拼成一幅森林夜路圖，後續案件可在地圖上開啟新地點或回訪角色。這條長線只提供好奇與回訪理由，各案仍可獨立理解和結案；不要求改寫黃金貓頭鷹案，也不預設後續案件內容。

### 試錯與驗收方向

每個必要結論都要有至少兩處可回看且互相支持的線索；時間、光線與路線規則需在遊戲內講清楚。不同居民的證詞不能因緊張、沉默或外表而被當作有罪證據。完整線索不足時允許玩家提出暫定解釋並回去調查；重試與提示不處罰玩家。

規則與五題已在案件資料和題型模組中實作；時間界線是「最後確定正常」到「最早確定偏移」，不把首次錯投時間誤當偏移開始。郵袋的圖形鎖從場景地標得解，不靠未提供的數字。每題可回看、重排或重新選擇，DOM 提供鍵盤與螢幕閱讀器的等效操作，包含收納及使用小物件。班級與個人試玩仍需驗收實際時長、手機閱讀距離和推理難度。

| 本案流程 | 首玩估時 | 推理負荷 |
| --- | ---: | --- |
| 委託、角色與調查方式 | 2–3 分鐘 | 低：理解事件與場景互動 |
| 小徑探索、查看線索與初次訪談 | 4–5 分鐘 | 中：區分看見的痕跡和推論 |
| 左右支路探索、收納與使用小物 | 8–10 分鐘 | 中：把各場景實物用在對應的比較位置 |
| 重排巡燈紀錄 | 3–4 分鐘 | 中：依時間先後找出異常 |
| 比對燈罩調整痕跡 | 3–4 分鐘 | 中：多種痕跡配對，避免單線索定人 |
| 重現燈光方向 | 4–5 分鐘 | 中：操作物件並檢查空間因果 |
| 解開郵袋封緘與核對投遞單 | 4–6 分鐘 | 中高：由地標暗碼辨路線，再核對時間與證詞 |
| 拼回事件順序、確認動機 | 3–4 分鐘 | 中高：串起五段事件及證據來源 |
| 收尾與結果回應 | 2–3 分鐘 | 低：把推理連回居民需要 |
| **合計** | **約 33–44 分鐘** | **中等，後段有一段中高整合** |

五題各聚焦一項操作和一個發現；主要難度集中在郵袋地標暗碼與最後因果排序。若實測時間常超過 45 分鐘，優先精簡重複文字或減少非必要點擊，保留關鍵推理步驟。

估時假設玩家會慢慢閱讀繁體中文、查看至少一次提示或回看線索，並可能由全班討論；快速點擊玩家和個別遊玩時間會不同。建議試玩時分別記錄個人及全班討論兩種情境，再調整謎題數量與對話長度。

## 後續驗收與系列規劃

- 偵探筆記微光印記的跨案呈現方式，以及是否要由系列第三案開始逐步揭露夜路圖。
- 班級試玩與個人遊玩的時長、文字可讀性及難度驗收結果。
