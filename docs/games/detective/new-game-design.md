# 新偵探遊戲｜框架設計

[遊戲目錄](../README.md) · [共用世界觀與遊戲設計準則](../../world/README.md)

本頁記錄線索座第二款偵探遊戲目前的框架。正式名稱、案件、教材、角色登場與美術仍待定案；現階段只有可進出的 Pixi 空場景、空物品欄及可收合的空對話框，沒有驗碼、存檔或解謎內容。黃金貓頭鷹是獨立校園案件，本遊戲預設屬於暮光森林，不沿用其劇情或儲存 ID。

## 六項開工要點

- **一句話委託**：暫定米洛邀玩家在暮光森林協助一位居民釐清生活中的小謎團；居民、地點與事件待定，不把暫定描述寫進遊戲台詞。
- **學習目標**：待案件教材確認。之後須讓玩家在場景中觀察、比對並使用線索來證明理解。
- **核心操作與規則**：框架預留場景、物品欄及對話三層；現在只有對話框收合，沒有可取得、組合或判斷的物件。成功條件與無效操作回饋待定。
- **場景草圖**：960×600 橫向畫布中央留給調查場所，底部是物品欄，其上是對話框；出口在畫布邊緣或頁面返回列。手機橫向顯示，直向將遊戲區旋轉並保留返回入口。角色、目標、進度與提示位置待定。
- **故事與彩蛋**：開場、過程、收尾和角色細節都待案件確定；框架不填入佔位劇情。
- **試錯與驗收**：目前可收合／重開對話框、回線索座；待玩法確定後再設計求助與重試。現階段驗收載入、空狀態、鍵盤／觸控、手機方向與兩種 base path。

框架入口為 [detective-new.html](../../../pages/detective-new.html)，場景與介面實作在 [detective-new](../../../src/games/detective-new/)；未來案件細節只在本文件補充，世界共用角色設定仍以 `docs/world/` 為準。
