# 魔法工坊｜場景美術

先讀 [共用世界觀](../../world/README.md) 與 [角色圖鑑](../../world/characters.md)。共用造型、配色、原圖與製作清單只維護在 [世界美術庫](../../world/art/README.md)；本文件只記工坊專屬的構圖與表現。

## 場景與材質

- 主要畫面是可操作的插畫工作台，參考親切角色的動作回饋、清楚的液體辨識與溫暖工坊氣氛。瓶子、魔力泉、回收釜與角色共用低俯視角、上左暖光與霧面材質；避免耀眼金屬、大面積白色高光。
- 工作台保留連續牆面、桌面及桌緣。角色站在櫃檯後，使用遮罩形成前後關係；背景只畫一次。物件接觸陰影與玻璃反光讓它們落在場景中。
- 魔力泉採開放式石池、後方小瀑泉與右側出水缺口；回收釜採銅褐中間調、低亮度紫光。兩者比瓶身有份量，並保留桌緣留白。
- 瓶身大小依容量決定，液量只改水位。羊皮紙承載委託、木牌承載操作，魔法書選難度、藥水表示關卡進度、結晶表示步數評價。全部採細緻插畫，幾何只用於不可見裁切。

角色動線、開場訂單、桌機／手機分區與全螢幕規則集中於 [玩法文件的場景與操作](design.md#場景與操作)。實際座標、瓶身尺寸與遮罩由 [scene-layout.ts](../../../src/games/magic-workshop/scene-layout.ts) 定義，不另抄一份像素表。

## 字體與資訊層次

使用本地 [Workshop Rounded](../../../assets/fonts/workshop/README.md)；標題與數字厚實圓潤，搭配深色描邊與短陰影。目標最醒目，瓶身數字清楚，米洛台詞中等字重，步數較小。字體載入失敗回退系統繁體字體。

紙面標題避開金屬封印，角色臉、目標與結晶分列；人物縮圖以 [portrait-framing.ts](../../../src/games/magic-workshop/portrait-framing.ts) 的臉部中心定位。文字不靠縮小字級塞滿，對話長度由 [story.ts](../../../src/games/magic-workshop/story.ts) 管理。出口用深木底象牙白叉號，保留可及性名稱。

## 動作與液體

- 首訪手勢直接示範操作；角色台詞保留陪伴語氣，不變成長篇教學面板。
- 拿放有抬升與落下，無效操作有短促回饋；液面依瓶內輪廓與有效面積呈現份量，傾倒時保持水平。光暈與水花不得遮住容量、目標或出口。
- 水流使用完整插畫貼圖變形；只有落點用少量水花。抬瓶、傾倒、收流與歸位以 [liquid-geometry.ts](../../../src/games/magic-workshop/liquid-geometry.ts) 的時序為準。
- 待機動態低幅度；背景分頁及減少動態直接收斂到必要結果。音效掛點與生命週期見 [動畫、素材與音訊](design.md#動畫素材與音訊)。

## 圖層順序

背景／遠景 → 訂單與進度 → 桌面 → 接觸陰影與環境光 → 角色及泉／釜 → 瓶後壁、液體、瓶前高光與數字 → 拖曳瓶、水流與焦點 → 對話、教學手勢與過關效果。角色與前景依櫃檯遮罩配置；光影不能壓暗關鍵資訊。

## 產製與驗收入口

[美術庫](../../world/art/README.md#製作清單與重建) 列出原稿、固定格規格、提示與重建腳本。先確認現役版本再產製，沿用角色物種、衣物、道具與比例。新增圖片及動畫幀遵循 [AGENTS 素材邊界](../../../AGENTS.md)，完整原圖與每個切出幀都要檢查；不得用裁切掩蓋碰線或跨格。實機操作驗收見 [遊戲驗收範圍](design.md#驗收範圍)。
