# 班級 RPG

## 班級 RPG：已確認方向

- 老師操作一台觸控電視，全班觀看、小隊討論、代表輪流操作；無學生帳號或居家登入。
- 課程 60～90 分鐘，遊戲約 10～15 分鐘；獎勵操作目標 2～5 秒。老師可中止或快速結算。
- 角色只含等級、經驗、HP／ATK／DEF、一把武器、一件防具、最多一隻寵物；無職業、自由配點或複雜技能樹。
- 成長上限 50 級，公式與裝備加成見 assets/js/class-rpg-model.js；經驗只增加，復原誤發除外。
- 已完成名冊、個人／小隊／全班獎勵、交易復原、成長同步、全班散步／暫停／選角。個人造型、寵物、冒險輪盤與事件尚未完成。
- 班級圖集 char1.webp 為 Mana Seed 512×512，8×8 格、每格 64px；方向 down/up/right/left，站姿上半第 0 欄，走路下半 0～5 欄，跑步 0,1,6,3,4,7；保持 nearest 取樣。
- 規劃循環：課堂表現 → 經驗／冒險能量 → 老師啟動輪盤 → 短事件 → 遊戲金幣。能量提高期待感，不用固定解鎖門檻；最低結果不扣分、不失裝備。
- 事件依剩餘時間分 2～4、5～8、8～12 分鐘；支援重轉、指定、延後與快速結算。每堂最多一個大型或兩個小型事件，不用事件產能量無限循環。
- 金幣用於外觀／裝備／寵物，不兌換現實獎勵。全班有基本獎勵，小隊表現可小幅加成；經驗以平時課堂為主。
- 雲朵勳章完全獨立：不得進 RPG、輪盤、商店、能力或金幣兌換；只由老師按實際表現發放。
- 不新增公開排名、死亡懲罰、扣既有經驗、個人小屋或即時多人戰鬥。
- 後續先驗證一個寶箱／金幣事件，再做簡化 Boss；能量公式、經濟、造型流程與小隊安排需依老師決定，不自行擴張。
