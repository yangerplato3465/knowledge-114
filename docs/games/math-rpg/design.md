# 數學勇者設計方向

目前為空白 Pixi 遊戲框架；新封面、像素遊玩場景與答題戰鬥尚未接入。舊五關戰鬥、單元選單、成長、獎勵、角色動畫與可見文字均已移除，題庫及單元目錄保留。使用者已指定沿用原答題戰鬥方向，後續逐步確認與實作。

本遊戲呈現暮光森林的[上古傳說](../../world/README.md#上古傳說與今日和平)。新人物的身分、個性與核准原畫只見[共用角色圖鑑](../../world/characters.md#上古傳說人物)，本頁只記遊戲的呈現差異。[美術來源與舊素材規格](art.md) 區分新原畫、參考稿與歷史素材，目前畫布皆未載入。

## 本階段六項開工要點

- **一句話委託**：透過數學挑戰認識上古傳說，遊戲第五關面對赫恩；具體開場與委託文案待確認。
- **學習目標**：沿用五上既有四組題庫與五上／六上單元分類，以數學作答支持冒險行動。
- **核心操作與規則**：預定維持答對出劍並壓回敵人蓄力、答錯受到反擊、蓄力滿受到攻擊的原方向；尚未重新實作，不新增赫恩專屬能力或替未定數值下結論。
- **場景草圖**：整頁單一 Pixi canvas；封面用已選定原畫，中央有開始入口與簡短玩法介紹，下方的世界介紹後續另行確認。遊玩維持像素風，先以兩張站立參考確認第五關方向，黎薇在左、赫恩在右。背景／角色／特效／介面圖層及座標尺寸見 [scene.ts](../../../src/games/math-rpg/scene.ts)，新內容均未接入。
- **故事與彩蛋**：共用歷史引用世界觀；舊文案已撤除，新台詞與彩蛋待確認，不延伸封印現況與人物下落。
- **試錯與驗收**：驗證題庫唯一正解、種子可重現、畫布載入／離場清理及橫直向縮放；新玩法的鍵盤、觸控與教室試玩在加入內容後驗收。

## 框架邊界

[MathRpg.tsx](../../../src/games/math-rpg/MathRpg.tsx) 只管理畫布生命週期及隱藏的輔助語意；頁面沒有可見導覽、卡片、表單或遊戲文字。載入失敗的狀態與重試操作僅提供給輔助技術，畫布可由重新整理再次載入。

[scene.ts](../../../src/games/math-rpg/scene.ts) 按需載入本地 Pixi ESM，建立空白圖層。新圖片、題目、答案與操作視覺皆應加入 Pixi；DOM 僅保留非視覺語意與鍵盤操作支援。背景沿用共用主題，圖層尚未放入任何圖片或文字。

畫布依容器縮放並支援高像素密度；目前按需重繪，不啟動動畫 ticker。逾時、離場及過期初始化都不得附加新畫布，離場銷毀 Pixi 與尺寸監聽。素材載入一律使用 `import.meta.env.BASE_URL`。

## 保留的題庫

單元分類與出題入口唯一來源為 [question-deck.ts](../../../src/games/math-rpg/question-deck.ts)，題目型別見 [questions.ts](../../../src/games/math-rpg/questions.ts)，固定種子亂數見 [question-random.ts](../../../src/games/math-rpg/question-random.ts)。亂數序列與原題庫一致，題幹、答案、提示、幾何圖形資料及難度標記保留，但尚未接入畫布。

| 單元 | 題庫來源與範圍 |
| --- | --- |
| 五上第 1 單元：多位小數與加減 | [decimal-questions.ts](../../../src/games/math-rpg/decimal-questions.ts)：小數加減、直接／反向取概數、排序與位值換算，四選一 |
| 五上合併第 2–3 單元：因數與倍數 | [factor-questions.ts](../../../src/games/math-rpg/factor-questions.ts)：因數、公因數、最大公因數、倍數、公倍數、最小公倍數及倍數判斷，四選一 |
| 五上第 4 單元：擴分、約分與通分 | [fraction-questions.ts](../../../src/games/math-rpg/fraction-questions.ts)：除法轉分數／帶分數、比較及擴約分填空；比較三選一，其餘四選一 |
| 五上第 5 單元：多邊形與扇形 | [geometry-questions.ts](../../../src/games/math-rpg/geometry-questions.ts)：第三邊、內角與扇形角度／全圓分數，含示意圖資料，四選一 |

五上其餘單元與六上目錄保留，但尚無題庫；出題入口必須拒絕，不得借用別的單元。題目範圍、數值與模板以各產生器為準；擴充仍須依教師題例，保證正解可驗算、選項互異、近期不重複、種子可重現。不得恢復已移除的舊固定題庫。
