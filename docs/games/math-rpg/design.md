# 數學勇者設計方向

目前可從 Pixi 上古決戰封面進入單元、選關及五關答題戰鬥。封面角色有微幅呼吸、衣角變形與滑鼠視差，底部玩法標語已移除；戰前保留快速說明。遊玩採像素背景與角色圖集，第一至第四關使用小型暫用怪物，第五關面對赫恩。成長與獎勵尚未接入。

本遊戲呈現暮光森林的[上古傳說](../../world/README.md#上古傳說與今日和平)。人物的身分、個性與核准原畫只見[共用角色圖鑑](../../world/characters.md#上古傳說人物)，本頁只記遊戲的呈現差異。[美術來源與舊素材規格](art.md) 區分現役封面圖層、像素參考稿與歷史素材。

## 本階段六項開工要點

- **一句話委託**：透過數學挑戰認識上古傳說，遊戲第五關面對赫恩；具體開場與委託文案待確認。
- **學習目標**：沿用五上既有四組題庫與五上／六上單元分類，以數學作答支持冒險行動。
- **核心操作與規則**：答對出劍並壓回敵人蓄力；答錯或蓄力滿受擊。錯題在攻擊後顯示正解與原題庫提示，等待使用者繼續才恢復計時。規則與暫定數值唯一來源為 [battle-model.ts](../../../src/games/math-rpg/battle-model.ts)，不新增赫恩專屬能力。
- **場景草圖**：整頁單一 Pixi canvas，封面分層插畫與像素戰鬥分開製作；黎薇在左、赫恩在右，共用腳底線。橫直向分別安排戰場、題目與選項，背景以圓弧青綠／尖角紫色的古代石庭對照。圖層與選單見 [scene.ts](../../../src/games/math-rpg/scene.ts)，戰鬥見 [battle-view.ts](../../../src/games/math-rpg/battle-view.ts)，封面動態見 [cover-motion.ts](../../../src/games/math-rpg/cover-motion.ts)。世界介紹後續確認。
- **故事與彩蛋**：共用歷史引用世界觀；舊文案已撤除，新台詞與彩蛋待確認，不延伸封印現況與人物下落。
- **試錯與驗收**：題庫唯一正解、種子可重現、連按／過期答案不重複傷害、超時只結算一次、暫停／解說停止計時、完整五關與同關重試、載入取消及橫直向瀏覽器驗證。教室平衡與實機觸控仍待試玩。

## 框架邊界

[MathRpg.tsx](../../../src/games/math-rpg/MathRpg.tsx) 沿用魔法工坊的共用網站導覽、主題切換、返回列與等寬遊戲外框，並管理畫布生命週期及隱藏的標題、玩法、狀態與語意按鈕。封面是遊戲內的開場；全螢幕按鈕在封面／選單與戰鬥暫停畫面內，由 Pixi 繪製。滑鼠／觸控與鍵盤呼叫同一場景操作，鍵盤焦點由 Pixi 繪製。Escape 優先退出全螢幕，再依所在場景返回選關、單元或封面；網站導覽的鍵盤操作不觸發遊戲返回。載入失敗可重試或返回單元。

[scene.ts](../../../src/games/math-rpg/scene.ts) 按需載入本地 Pixi ESM，所有可見背景、角色、題目、示意圖與操作皆在 Pixi。封面 MeshSimple 下方頂點固定，圖片入口為 [cover-art.ts](../../../src/games/math-rpg/cover-art.ts)。戰鬥的 AnimatedSprite 四幀待機、六幀攻擊及獨立劍弧／命中星芒由 [battle-art.ts](../../../src/games/math-rpg/battle-art.ts)載入；共同圖集以引用租約管理，舊場景不得卸載新場景正在使用的素材。

畫布依容器縮放並支援高像素密度。封面與戰鬥使用私人 ticker，AnimatedSprite 不訂閱共享 ticker。[battle-effects.ts](../../../src/games/math-rpg/battle-effects.ts) 依結算時間呈現出招軌跡及命中，即使更新間隔較長也能直接顯示命中；暫停凍結，離場清除。降低動態停止角色循環與飛行，保留靜態命中標記及同一答題計時、傷害規則；隱藏頁面自動暫停戰鬥，回來後手動繼續。逾時、離場及過期初始化不得附加場景；離場銷毀 Pixi、素材、字體、計時器與監聽。素材載入一律使用 `import.meta.env.BASE_URL`。

## 五關操作原型

選定已開放單元後可直接選任一關，方便驗收魔王關，也能從第一關依序完成五關。答對扣敵人生命並壓回蓄力，答錯或蓄力滿扣勇者生命；攻擊期間禁止重複作答與計時。過關後可前往下一關並小幅回血；第五關完成即結束，失敗可回滿生命再戰本關。沒有第六關、解鎖條件、成長卡、獎勵或進度存檔。

生命、蓄力時間、壓回量與攻擊結算時間皆為本輪操作驗收用的暫定值，以 [battle-model.ts](../../../src/games/math-rpg/battle-model.ts)為準，尚未完成教室平衡。

## 保留的題庫

單元分類與出題入口唯一來源為 [question-deck.ts](../../../src/games/math-rpg/question-deck.ts)，題目型別見 [questions.ts](../../../src/games/math-rpg/questions.ts)，固定種子亂數見 [question-random.ts](../../../src/games/math-rpg/question-random.ts)。四組既有題庫已接入畫布，產生器、題幹、答案、提示、幾何示意資料及難度標記保留。

| 單元 | 題庫來源與範圍 |
| --- | --- |
| 五上第 1 單元：多位小數與加減 | [decimal-questions.ts](../../../src/games/math-rpg/decimal-questions.ts)：小數加減、直接／反向取概數、排序與位值換算，四選一 |
| 五上合併第 2–3 單元：因數與倍數 | [factor-questions.ts](../../../src/games/math-rpg/factor-questions.ts)：因數、公因數、最大公因數、倍數、公倍數、最小公倍數及倍數判斷，四選一 |
| 五上第 4 單元：擴分、約分與通分 | [fraction-questions.ts](../../../src/games/math-rpg/fraction-questions.ts)：除法轉分數／帶分數、比較及擴約分填空；比較三選一，其餘四選一 |
| 五上第 5 單元：多邊形與扇形 | [geometry-questions.ts](../../../src/games/math-rpg/geometry-questions.ts)：第三邊、內角與扇形角度／全圓分數，含示意圖資料，四選一 |

五上其餘單元與六上目錄保留，但尚無題庫；出題入口必須拒絕，不得借用別的單元。題目範圍、數值與模板以各產生器為準；擴充仍須依教師題例，保證正解可驗算、選項互異、近期不重複、種子可重現。不得恢復已移除的舊固定題庫。
