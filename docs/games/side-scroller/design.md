# 橫向遊戲框架

[遊戲目錄](../README.md) · [共用世界觀](../../world/README.md)

目前是單人橫向平台操作原型，名稱、教材、正式關卡與角色美術尚未定案。冒險座以「橫向遊戲框架」作暫時入口。採用橫向平台遊戲的移動、跳躍與鏡頭結構，場景與測試角色以 Pixi 幾何形狀搭建；本遊戲的米洛圖片已移除，等待使用者重新設計風格。

## 六項開工要點

- **一句話委託**：米洛試走森林小徑，到右方的星燈集合點；目前只用這條路測試操作。
- **學習目標**：本階段驗證方向、距離及起跳時機的操作回饋；學科教材尚未加入。
- **核心操作與規則**：左右移動、加速跑與可變高度跳躍；實體平台阻擋側面和頭頂，木橋可由下方穿過；途中可收集星光，經過路標記錄重生點，跌落會回到最近路標，抵達終點即可完成試走。
- **場景草圖**：由左至右安排安全起跑區、低階梯、木橋、缺口、重生路標與星燈；鏡頭跟隨米洛，畫面上方呈現星光與操作提示。手機改用較高視窗，底部提供左右、跑步及跳躍按鈕，出口保留在場景外。
- **故事與彩蛋**：米洛的角色身分見共用圖鑑；本遊戲造型等待重新設計。正式開場、居民委託與收尾待玩法確認，本階段不擴寫劇情。
- **試錯與驗收**：可暫停與重新試走，跌落保留星光並重生。驗證平台四向碰撞、跳躍緩衝、離地寬限、重生、終點及不同幀率；實機檢查鍵盤、觸控、鏡頭及離場清理。

## 測試角色與美術狀態

角色身分只維護在[圖鑑](../../world/characters.md)。本遊戲專用的米洛原稿、執行圖、預覽及其加工／載入引用已清除。目前 [scene.ts](../../../src/games/side-scroller/scene.ts) 用與碰撞體同尺寸的幾何測試角色呈現位置與朝向，沒有角色圖片或腳下陰影；新風格與動作素材尚未產製。

減少動態時關閉裝飾飄動與鏡頭緩動，碰撞與跳躍規則一致。遊戲不連線、不保存玩家資料。測試角色尺寸、操作與關卡數值以 [model.ts](../../../src/games/side-scroller/model.ts) 為唯一來源。
