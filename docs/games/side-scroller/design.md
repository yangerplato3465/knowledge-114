# 橫向遊戲框架

[遊戲目錄](../README.md) · [共用世界觀](../../world/README.md)

目前是固定向前跑、以紅藍切色改變地形實體的原型，正式名稱、教材與角色美術尚未定案。冒險座以「橫向遊戲框架」作入口。依使用者提供的 Kenney 範例，以晴空、遠山、樹影及暖沙色地形製作暮光森林的白天小徑，部分地板與平台改成紅藍地形。

## 六項開工要點

- **一句話委託**：先巡覽森林小徑，確認日後角色固定向前跑時的路線；居民委託待定。
- **學習目標**：本階段驗證地形距離、一段跳起跳時機與空中切色反應，學科教材尚未加入。
- **核心操作與規則**：開場自動循環巡覽，隱藏測試角色；切換「試跑」後測試方塊固定向右跑，只能一段跳，沒有左右與加速控制。無失誤的一關以約 45 秒為目標，實際時長由 [model.ts 的 LEVEL_SECONDS](../../../src/games/side-scroller/model.ts) 依起點、終點與跑速計算。緩坡可直接行走，高臺離緣後自然下墜；空中平台承擔跨大洞、逐步登高與連跳通路。跌入洞底回到最近落腳區，走到終點停止。
- **場景草圖**：由安全起跑、小洞與上坡進入低谷，再依序安排大斷谷渡橋、高臺登頂、明顯下墜與寬落地區、高低交錯的連續平台，最後接緩坡和終點小洞。紅藍地形穿插於小洞兩側、登高地板與必要平台；正常地面保留起點、落腳區及喘息區。雲層、遠山與樹影以不同速度捲動。手機直向使用較高視窗，左下方提供紅藍按鈕，試跑時右下方提供跳躍鍵；巡覽、暫停、重來與出口位於場景外，全螢幕保留退出與返回。
- **故事與彩蛋**：共用角色身分見[圖鑑](../../world/characters.md)，角色造型等待重新設計。本階段製作地形與背景，正式劇情待玩法確認。
- **試錯與驗收**：可暫停、從頭開始與切回巡覽；跌入洞底自動重生，重生高度依落腳區表面計算。測試固定前進、一段跳、上下坡、自然下墜、必要平台通行、切色失去支撐／下降落地、不同高度重生、終點與不同顯示幀率；整條驗收路線須配合切色、無重生、站遍必要平台並在 40–50 秒完成。另以瀏覽器確認紅藍實體與透明地形、切色控制、素材及捲動。

## 世界切色

初始紅藍地形皆透明、不可踩；紅色 ▲（按鈕或鍵盤 1）使紅色地形成為實體、藍色透明，藍色 ●（按鈕或鍵盤 2）則相反。正常地形始終可踩。切走腳下顏色立即失去支撐；跨交替色平台須先起跳，再切下一色，空中仍只有一段跳。透明地形不碰撞，切色不把玩家瞬移到平台表面。

巡覽也能切色，暫停巡覽時可檢視不同版本；試跑暫停與完成時停用切色。巡覽／試跑切換保留所選顏色，從頭開始回到未選色，跌落重生保留顏色。按鈕以文字、形狀及選取狀態提示，地形同步使用紅三角／藍圓形；切色後焦點回到遊戲區，可接續鍵盤跳躍。

## 美術與來源

使用者指定的 **Kenney New Platformer Pack 1.1**（CC0）來自本機下載資料夾。現役素材為 [`assets/images/side-scroller/kenney/`](../../../assets/images/side-scroller/kenney/)，包含 Double 尺寸的雲層、遠山、樹影與沙土地板／平台；原授權見 [license.txt](../../../assets/images/side-scroller/kenney/license.txt)。圖片保留原檔，不產製角色或加入收集物。

地板以原圖拼接，坡面頂部依碰撞高度傾斜；所有地形位置、顏色、碰撞與透明度常數 `GHOST_ALPHA` 由 [model.ts](../../../src/games/side-scroller/model.ts) 維護。[scene.ts](../../../src/games/side-scroller/scene.ts) 使用相同表面繪製，以 Pixi 色彩矩陣保留原素材紋理與外形，紅藍實體與透明版共用染色，只改透明度。濾鏡套在完整地形群組，避免重疊磁磚累加透明度。背景維持原色。方塊僅用於試跑位置驗證，正式角色未加入。

減少動態時停止背景視差，固定前進及跳躍規則一致，並可隨時暫停。遊戲不連線、不保存玩家資料。
