# 魔法禁書庫

[遊戲目錄](../README.md) · [共用世界觀](../../world/README.md)

固定向前跑、以紅藍燈組合改變地形實體的色彩冒險，學科教材尚未加入。冒險座以「魔法禁書庫」作入口。依使用者提供的 Kenney 範例，零至三星以晴空、遠山、樹影及暖沙色地形製作暮光森林的白天小徑，平地與平台穿插紅、藍、紫特殊地形；四星改為暮色灰石小徑，加入消散障礙與上下岔路。

## 六項開工要點

- **一句話委託**：米洛誤入藏著色彩魔法的神祕空間；陪他穿過浮空小徑，找出傳送出口。
- **學習目標**：由單色開燈與一段跳，逐步進入紅藍燈組合及空中切色反應；四星需分辨同色平台成實體、同色直立方塊消散的不同規則，並以起跳時機選擇上下路線。學科教材尚未加入。
- **核心操作與規則**：開場先閱讀三頁玩法手冊，背景跑道凍結；選擇「開始冒險」後米洛固定向右跑，只能一段跳，沒有左右與加速控制。亦可先關閉手冊巡覽地圖。零星入門跑道約 30 秒，一星約 35 秒、二星約 42 秒；原有跑道定為三星，無失誤維持 40–50 秒。四星約 50 秒，新增消散障礙與上下岔路。實際時長由 [model.ts 的 levelSeconds](../../../src/games/side-scroller/model.ts) 依所選關卡起點、終點與跑速計算。緩坡可直接行走，高臺離緣後自然下墜；空中平台承擔跨大洞、逐步登高與連跳通路。跌入洞底回到最近落腳區。零至三星最後的特殊地板後接一段正常平地，不必再換燈；必須碰到尾端傳送門才完成，米洛短暫淡出進入出口。地形、出口位置與接觸判定由 model 維護。
- **場景草圖**：下述登高、斷谷與連續切色屬於三星跑道；零星以平地、兩個小洞與緩坡練習。三星前段用正常地面、小洞、緩坡與分散紅色地板暖身，特殊地板之間留正常地面。中段大斷谷以藍色／正常平台交錯，先練連跳、無須空中換色；登高時才引入紫色，經正常平台準備後前往紫色高臺。登頂、明顯下墜與寬落地區提供喘息，接一段分散藍色地板。後段才安排無縫紅紫地板、三色交替空中平台及終點前換色。正常地面保留起點、落腳區及挑戰之間的準備空間。雲層、遠山與樹影以不同速度捲動。手機直向使用較高視窗，底部依序提供跳躍、紅燈、藍燈三個大觸控按鈕，紅藍燈可同時開啟；巡覽時保留但停用跳躍鍵；巡覽、暫停、重來與出口位於場景外，全螢幕保留退出與返回。
- **故事與彩蛋**：共用角色身分與核准的 Q 版空手米洛見[圖鑑](../../world/characters.md)。米洛使用核准的空手跑跳動畫，傳送門為神祕空間的出口。開場委託由第一頁手冊說明，四星仍延續尋找出口的委託，尚無其他故事事件。
- **試錯與驗收**：可暫停、從頭開始與切回巡覽；跌入洞底自動重生，重生高度依落腳區表面計算。測試固定前進、一段跳、上下坡、自然下墜、必要平台通行、兩燈組合／獨立關閉、切色失去支撐／下降落地、不同高度重生、終點與不同顯示幀率；三星驗收路線須配合三色切換、無重生、站遍必要平台並在 40–50 秒完成；零星須配合兩次一段跳與分散切燈、無失誤在約 30 秒完成。另驗證前段單色分散、相鄰異色留到後段，以及起跳／切色時機前後偏移仍能通關，避免必須精準到單一物理步長。以瀏覽器確認前後段地形、三色實體與透明地形、淡光、兩按鈕操作及捲動；實際難度仍待玩家試跑調整。

## 關卡與難度

[model.ts](../../../src/games/side-scroller/model.ts) 的 LEVELS 維護可選關卡；LEVEL_ZERO 為預設入門，LEVEL_ONE 為平台練習，LEVEL_TWO 為連色練習，LEVEL_THREE 保留原跑道，LEVEL_FOUR 為「晶石岔路」。各自持有地形、世界寬度、落腳區及出口，場景、碰撞與重生共用所選關卡，切換會取消舊載入並重新開啟巡覽。難度型別支援 0～6 星，目前實作 0～4；以共用的[金色星星圖片](../../world/art/side-scroller/difficulty-star-manifest.json)加數字表示，不用星星數量堆疊。

零星前半僅紅、藍，紫色在後半引入。每段特殊地板前後皆為正常地面，色塊之間保留數秒行走距離，兩次小洞跳躍與切色分開；沒有連續特殊地板、空中切色或高臺落差。緩坡提供輕微高低變化，最後接長段正常地面與旋轉出口。數值以關卡表與 levelSeconds 為準。

一星縮短特殊地板之間的正常路面，增加紅、藍、紫的出現頻率，仍不安排相鄰色塊，紫色留在後半。前段保留一個小洞，中段兩座浮空平台承擔跨斷谷與逐步登高的用途；平台段維持藍燈，無須空中切色，正常高臺提供落地與下一次換燈的準備空間。後段緩坡下降、密集但分隔的三色地板，最後仍接正常跑道與出口。驗收包含一段跳站遍必要平台、切燈與起跳時機前後偏移後仍可約 35 秒通關。

二星維持接近一星的特殊地板出現頻率，延長至約 42 秒，沿用跨洞登高平台，並只安排兩處相鄰雙色地板：藍接紫、紫接紅。先起跳、再切換單一燈，分別是開紅燈與關藍燈；每組前後都保留正常地面。其餘色塊分散，兩組之間有切色、緩坡與恢復空間，出口前仍接正常跑道。驗收需落在兩組各自的第二色塊，切色／起跳前後偏移也能無失誤通關；不切該盞燈就會跌落。手機選關改為兩欄，全螢幕遊戲區使用剩餘高度，保留所有難度選項與操作空間。

四星「晶石岔路」約 50 秒，起點／出口與時長仍由 LEVEL_FOUR 與 levelSeconds 維護。前段以正常灰石地面和三個獨立坑洞引入紅、藍、紫直立方塊，再安排兩段上下並行的平台：不提早跳高可走下路，平台較寬、跳躍較少，但須消散跨洞障礙；提早起跳可走上路，平台較窄，須連跳並在空中換色。每段岔路皆回到正常地面，兩次路線選擇互相獨立。後段串接三色直立障礙，最後接正常地面與出口；上下路沒有額外獎勵或尚未定案的功能。

直立方塊是四面障礙，與單向落地的平台分開判定。只有精確相同光色才可穿過（紅燈單開消紅、藍燈單開消藍、兩燈同開消紫）；其餘狀態皆阻擋。消散時保留極淡輪廓，透明度由 model 的 OBSTACLE_GHOST_ALPHA 維護。撞到方塊即停止水平前進、取消跳躍與平台落地，掉至洞底才重生；事後切色無法取消此次撞擊，重生保留燈光並恢復固定跑速。四星驗收須涵蓋上下路四種組合、前後時機偏移、必要平台落地、同色穿越／異色撞落、紫色組合及重生恢復。

## 世界切色

紅燈（按鈕或鍵盤 1）與藍燈（按鈕或鍵盤 2）獨立保持開關狀態，按一下切換，再按關閉；可用滑鼠依序開兩燈，或用多指觸控同時操作，不必一直按住。初始兩燈關閉，特殊地形皆透明、不可踩。只有紅燈開啟時，紅色 ▲ 為實體；只有藍燈開啟時，藍色 ● 為實體；兩燈都開啟時，紫色 ◆ 為實體，紅藍地形仍透明。正常地形始終可踩。切走腳下顏色立即失去支撐；跨交替色地板與平台須先起跳，再切下一色，空中仍只有一段跳。透明地形不碰撞，切色不把玩家瞬移到平台表面。

巡覽也能切色，暫停巡覽時可檢視不同版本；試跑暫停與完成時停用切色。巡覽／試跑切換保留兩燈狀態，從頭開始關閉兩燈，跌落重生保留燈光。底部依序為金黃色跳躍鍵、紅燈鍵、藍燈鍵。按鈕使用 Kenney UI Pack 的圓角立體圖片，由 [controls.ts](../../../src/games/side-scroller/controls.ts) 以 Pixi 九宮格與文字繪製；按鈕僅顯示置中的跳躍、紅燈、藍燈大字，不顯示副標或快捷鍵。按下時換為壓平圖片並下沉；跳躍鍵放開回彈，紅藍燈開啟後保持壓下，關閉才彈回，暫停也保留燈的選取外觀。觸控與鍵盤共用回饋；減少動態時即時切換按壓狀態。尺寸與間隔由 CSS 依遊戲區調整，大電視全螢幕放大觸控目標，手機仍保留三鍵。DOM 按鈕只負責對齊的觸控範圍、語意與鍵盤焦點，三鍵各自擷取 pointer，取消接觸、失去擷取、離焦、暫停與離場都釋放按壓；多指跳躍與切燈互不干擾。指標按下即切換，後續 click 不重複切換；鍵盤長按不連續切燈。地形維持紅三角／藍圓形／紫菱形，切色後焦點回到遊戲區，可接續鍵盤跳躍。

## 開場玩法手冊

[Tutorial.tsx](../../../src/games/side-scroller/Tutorial.tsx) 維護三頁共同內容：禁書庫背景與一段跳／出口、點燈實體與關燈掉落、紅藍混成紫色。選四星時先凍結場景並開啟第四頁「消散方塊，選擇岔路」，也可往前翻閱共同內容。[TutorialDemo.tsx](../../../src/games/side-scroller/TutorialDemo.tsx) 使用相同米洛／地板／傳送門素材在 Pixi 內示範，第四頁並列同色消散與異色撞落；減少動態保留靜態對照。外框採素材包的粗輪廓、暖金邊與奶油紙面，[來源與尺寸](../../world/art/side-scroller/manual-frame-manifest.json) 另有紀錄。

手冊是原生 modal dialog，支援上一頁／下一頁、頁碼、左右方向鍵及水平觸控滑動；換頁焦點回標題，Escape 或「先看世界」可關閉，不會自動啟動冒險。遊戲中重看會凍結當前跑道與清空按鍵，關閉後保持原來的暫停狀態。手機與橫向短視窗的內容可垂直捲動，翻頁控制保持可見。減少動態時用靜態正反例及文字解釋，玩法不變。原本場景角落說明與下方長段落已由手冊取代，鍵盤操作說明仍提供給輔助科技。

## 美術與來源

使用者指定的 **Kenney New Platformer Pack 1.1**（CC0）來自本機下載資料夾。現役素材為 [`assets/images/side-scroller/kenney/`](../../../assets/images/side-scroller/kenney/)，包含 Double 尺寸的雲層、遠山、樹影與沙土地板／平台；原授權見 [license.txt](../../../assets/images/side-scroller/kenney/license.txt)。素材包圖片保留原檔，不加入收集物。觸控按鈕另使用使用者提供的 **Kenney UI Pack 2.0**（CC0），採用黃色、紅色、藍色各自的凸起／壓平圖片，來源與現役檔名見[觸控素材清單](../../world/art/side-scroller/touch-controls-manifest.json)，授權隨圖片保留。

四星灰石與方塊直接採用素材包 `Sprites/Tiles/Double/` 的 `terrain_stone_block_top`、`terrain_stone_block_center`、`terrain_stone_horizontal_left/middle/right`、`block_red`、`block_blue`，原檔同名置於上述現役目錄。每張都是單格 128×128 PNG，以左上角定位、完整縮放，無裁切或重製圖表；紫色障礙由藍方塊在場景染色產生。背景沿用原雲層／遠山／樹影，以靛紫天空、淡月與星點呈現暮色；遠山與樹影以不同透明度保留深度，不對白色天空區染色造成矩形接縫。岔路旁直接在世界標示「上路・連跳換色／下路・寬臺跨洞」。零至三星仍使用原沙土地形與背景；各關只載入自身所需的地板素材。

米洛沿用核准的右向 Q 版、粗輪廓、空手造型，僅製作跑步與跳躍。金色／青綠圓環傳送門以核准母圖的固定角度旋轉製成 8 幀。三張透明圖表與幀序／時長見 [sprite metadata](../../../assets/images/side-scroller/sprites-v1.json)，產圖提示、來源與驗收見[製作清單](../../world/art/manifests/side-scroller-sprites-manifest.json)。[加工腳本](../../../scripts/prepare-side-scroller-sprites.mjs) 重建圖表，並在 `.art-output/side-scroller/animation/` 產生 GIF 與可播放的 `preview.html`。[art.ts](../../../src/games/side-scroller/art.ts) 共用固定格切片與角色動作控制，場景與教學各持有自己的紋理及 ticker，離場／翻頁時銷毀，不共用可被舊場景銷毀的全域紋理。

地板以原圖拼接，坡面頂部依碰撞高度傾斜；所有地形位置、顏色、碰撞與透明度常數 `GHOST_ALPHA` 由 [model.ts](../../../src/games/side-scroller/model.ts) 維護。[scene.ts](../../../src/games/side-scroller/scene.ts) 使用相同表面繪製，以 Pixi 色彩矩陣保留原素材紋理與外形，三色實體與透明版共用染色，只改透明度。濾鏡套在完整地形群組，避免重疊磁磚累加透明度。當前燈光以淡紅／藍／紫光鋪滿場景，亮度由 `LIGHT_ALPHA` 維護；特殊地形畫在光層上方，保持原本染色、輪廓與透明度，控制文字也不受染色。兩燈關閉即移除淡光。米洛與傳送門使用固定格 sprite sheet，跑步循環、依垂直速度選擇跳躍姿勢、落地壓縮與淡出收尾均由同一場景時鐘控制；暫停與閱讀手冊會一併凍結。

減少動態時停止背景視差，固定前進及跳躍規則一致，並可隨時暫停。遊戲不連線、不保存玩家資料。
