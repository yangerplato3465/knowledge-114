# 數學勇者設計方向

## 目前進度

第一階段的操作骨架已完成，第二階段的數值平衡已大致完成；目前五關版本作為後續製作基準，可進入正式題目內容階段。已確認勇者 HP 固定為 200、怪物逐關增強、受擊逐次增傷、答題後自動接題，以及可凍結戰鬥與回饋的暫停功能。

五上第九冊「多位小數與加減」及合併第 2–3 單元「因數與倍數」已接入動態題庫，其餘單元待題例與規則確認。尚未完成學生教室試玩，須以紙筆作答情況校準傷害及節奏，不把原型平衡模擬當成學生實測。敵人命名、美術與獎勵仍待定案。

## 目標與範圍

- 以一個年級、單一數學單元的基礎複習題，構成一局約 9～12 分鐘的互動遊戲。
- 學生透過選擇正確答案讓勇者攻擊敵人；在帶有壓力的節奏中複習，而非把遊戲做成計時測驗或長篇 RPG。
- 核心體驗是「有樂趣、有興趣、有複習」；錯答可得到短提示並繼續挑戰，不設永久扣分、公開排名或懲罰。
- 第一版為單人操作、可供同學討論的遊戲。多人同步、帳號、長期能力養成與獎勵發放流程不在本設計範圍。

## 單局流程

```text
選擇年級與單元
  → 第 1 關
  → 三選一成長
  → 第 2 關
  → 三選一成長
  → 第 3 關
  → 三選一成長
  → 第 4 關
  → 三選一成長
  → 第 5 關魔王戰
  → 勝利獎勵事件與本局回顧
```

- 目標採五關制；若實測後發現對特定單元或教室情境過長，才考慮縮為四關，不能以減少題目品質取代節奏調整。
- 前四關結束後各提供一次三選一，共四次局內成長。每局重新開始，成長不造成下一局的永久能力差距。
- 遊戲須在每局完成後進入獎勵事件；獎勵內容、實體獎勵規則、發放人與驗證方式待另行設計。未定案前，不將它實作為遊戲幣、永久戰力或自動兌換。

## 第一階段：UI 版位與操作骨架

目前已完成資訊位置、操作順序與戰鬥節奏的操作骨架，尚未製作最終轉盤或角色、敵人、背景圖片。畫面以語意化文字、既有主題色與簡單輪廓／色塊佔位；像素素材完成後只能替換視覺層，不改變控制項位置與流程。

桌面版戰鬥畫面由上而下安排如下：

```text
勇者名稱、HP／狀態       第 N／5 關、暫停       敵人名稱、HP／狀態
┌─────────────────────────────────────────────────────────┐
│                     戰鬥場地與角色佔位                    │
└─────────────────────────────────────────────────────────┘
敵人下一次攻擊的蓄力／預警
題幹與必要的一行提示
[ 選項 1 ] [ 選項 2 ]
[ 選項 3 ] [ 選項 4 ]
```

- 勇者 HP 固定在左上、敵人 HP 固定在右上，關卡與暫停置中；學生不需在答題時尋找最重要的戰況資訊。
- 戰鬥場地保留固定比例，避免攻擊、答題回饋或 HP 變化造成畫面跳動。敵人預警置於題目前，讓學生作答前能看見壓力來源。
- 題幹與答案皆由 DOM 呈現；四個選項在桌面為 2×2 格。每個按鈕保有可觸控的最小尺寸、明顯焦點與鍵盤 1～4 對應。
- 窄螢幕時維持 HP 資訊在戰場上方；答案可改為單欄，不能橫向捲動或因像素畫布擠壓題幹。題目正文優先於裝飾畫面。
- 三選一沿用同一個題目區域，以三張大按鈕取代四個答案；暫停、回饋、失敗與勝利皆不應讓戰鬥計時繼續推進。

## 戰鬥規則

目前可玩原型的數值唯一來源為 [battle.ts](../src/games/math-rpg/battle.ts) 的 `BALANCE` 與 `BATTLE_PACING`；目前平衡已大致完成，採用此版本作為後續內容製作基準，教室試玩校準仍待進行。

勇者 HP 上限固定為 200，成長、治療與再戰皆不得提高上限。怪物血量至少為勇者兩倍，勇者基礎攻擊與攻擊卡同步放大，讓怪物具有厚血量外觀，而非延長每關題數。蓄力攻擊保留思考空間，錯答反擊傷害較高；兩者仍共用本關逐次增傷。具體血量、傷害、過關回復與卡牌數值以 `BALANCE` 為準，單元蓄力週期以 `BATTLE_PACING` 為準。

各關的首次蓄力攻擊與錯答反擊都有獨立、逐關提高的基礎傷害，蓄力週期逐關縮短；魔王不再沿用前一關的攻擊力。為保留高傷害下的應對空間，答對的基礎壓回蓄力與過關回復同步調整。此版允許慢速玩家需要本關再戰，模擬的慢而準首次通關底線調整為一半，一般作答、亂猜與路線差距的檢查維持原標準；這是難度設計目標，並非學生實測通關率。

- 題目維持四選一；「三選一」只用於戰鬥後的成長卡，不與數學作答選項混用。
- 答對時，勇者以劍攻擊敵人；答錯時顯示一行內的觀念提示，並讓敵人取得反擊機會。
- 不作答時敵人持續蓄力，蓄滿便攻擊並開始下一輪蓄力。錯答反擊先顯示傷害預告，短暫回饋結束後自動結算傷害並將蓄力歸零；已經反擊就不保留上一輪蓄力。反擊有最低傷害，避免高護甲與快速亂按形成無傷通關。
- 答題後自動接續下一題、成長選擇或結局，不再要求按「下一題」。答對／答錯的停留時間見 `BALANCE.feedbackMinimum`／`wrongFeedbackSeconds`；錯答多留閱讀時間。暫停與隱藏頁面凍結剩餘回饋時間，返回後繼續倒數；回饋中按暫停仍可查看該題、正解及提示。三選一維持手動選擇。
- 同關每次實際受擊都使下一擊更痛，反擊與蓄力攻擊共用紀錄：`本次傷害 = max(該攻擊扣除護甲後的基礎傷害, 上次傷害 + hitGrowth)`，第一擊只算基礎傷害。採線性增傷，不設本關增傷上限；過關及本關再戰時歸零，答對、暫停或閱讀提示不會清除。畫面顯示本關受擊次數與下一擊傷害；HP、增幅等數值以 `BALANCE` 為準。
- 敵人必須頻繁製造攻擊壓力。攻擊以可見的蓄力條、明確預警與像素動作呈現；答對能壓回或打斷其攻擊進度。題目回饋、三選一、暫停與離開頁面時，戰鬥計時不得繼續推進。
- 勇者與敵人都使用「目前 HP / 最大 HP」數值與血條。傷害、治療與蓄力變化以明確數字回饋，不採一格一格的生命表現。
- 勇者 HP 上限維持已確認的固定值；後續依正式題目與實際試玩調整傷害、敵人攻擊間隔與卡牌效果，檢查關卡所需答對數及通關率。
- 失敗可回滿 HP 再戰同一關，敵人 HP、蓄力與本關增傷重設；保留已選成長卡，不重發卡牌，不能扣除外部獎勵或長期進度。

## 關卡與敵人

- 每關設計兩種同階候選敵人，進關時隨機擇一，形成最多 32 種五關敵人路線。
- 同一關的兩種敵人要有相近的預期戰鬥時間與難度，差別放在攻擊節奏、動作與應對方式，不能讓隨機結果造成明顯不公平。
- 第一關可使用史萊姆或哥布林；後續敵人依序提高輪廓、特效、攻擊預警與氣場的危險感，最終為魔王戰。
- 敵人的特殊行動必須可讀：例如慢而重的大招、快速的低傷攻擊、護盾或蓄力。不得要求學生閱讀額外數學規則，或以無預警的高傷害取代難度設計。

## 局內三選一成長

- 每次選擇提供三張效果清楚、立即可理解的成長卡。選項應涵蓋攻擊、防守與節奏控制，避免抽到三張都不適合當前戰況。
- 目前每次固定提供「磨利劍鋒」（提高答對傷害）、「穩固護甲」（增加護甲並回復 HP）、「沉著應戰」（答對時多壓回蓄力並回復 HP），可重複選取。效果與數值以 [battle.ts](../src/games/math-rpg/battle.ts) 的 `CARD_INFO` 與 `BALANCE` 為準。
- 連續答對加成、護盾與魔王專用增益尚未實作；若後續加入，須重新驗證卡牌與戰鬥平衡。
- 卡牌不使用複雜技能樹、自由配點、裝備欄或需要大量閱讀的組合規則；學生應能在十幾秒內作出選擇。

## 題目與內容生成

- 每局只使用一個年級與單元；關卡提升的是戰鬥壓力與成長組合，不任意加入其他單元內容。
- 單元目錄與開局入口見 [question-deck.ts](../src/games/math-rpg/question-deck.ts)，分類為「五上／六上」。舊固定題與除法產生器已移除；`questions.ts` 僅保留題目型別，目前五上第一單元及合併第 2–3 單元可開局。
- 其餘單元顯示「尚未開放」，介面與出題入口均禁止開局，不借用其他單元題目。正式題目量須涵蓋錯答與再戰需求，避免短時間內重複。
- 六上第十一冊的九個單元暫依教師提供的去年清單，名稱與順序以單元目錄為準；教材若有調整，再依教師確認更新。
- 題目擴充以教師提供的範例為來源：先分析可替換的數字、數值範圍、解題規則、答案格式與常見錯法，再建立可重現的隨機題目產生器；不在玩家遊戲時使用 AI 即時出題。
- 產生器必須保證正解可驗算、四個選項互異、正確索引正確，並避開不自然的數值、超出年級範圍的小數、負數或歧義題目。產出規則與亂數序列須可測試。
- 每道題後的提示應短且針對觀念；題幹、選項和提示均需使用適合臺灣小學教學的繁體中文用語與單位。

### 五上第九冊第一單元

- 實作與出題數值規則見 [decimal-questions.ts](../src/games/math-rpg/decimal-questions.ts)：小數加法、減法、直接四捨五入、反向找原數、直接排序與位值換算排序，皆為四選一。每輪混合各題型，近期題幹不重複，亂數種子可重現。
- 運算元小於 100、最多五位小數；加減答案與數值選項介於 0～100。取概數涵蓋個位至千分位，保留指定小數位；比較題不含相等數。以整數位值驗算，反向取概數僅有一個符合條件的選項。
- 允許紙筆計算，不以心算速度設計；五關混合同單元題型，不逐關提高數學難度。戰鬥數值暫沿用原型，遊戲時長及連續借位題的壓力仍待教室校準。

### 五上第九冊第 2–3 單元：因數與倍數

- 合併原第 2、3 單元，選單標示「2–3. 因數與倍數」，後續保留課本第 4～10 單元編號；六上目錄不變。
- 題型與數字範圍見 [factor-questions.ts](../src/games/math-rpg/factor-questions.ts)：找因數、公因數、最大公因數、倍數、公倍數、最小公倍數及快速判斷 2／5／10 的倍數。一般題使用百以內正整數，快速判斷使用三～五位整數。
- 公倍數與最小公倍數至少一個給定數大於 9，且兩數沒有直接倍數關係，避開只靠九九乘法表或較大數本身就能作答的組合。題目與選項均可驗算，四選一只有一個正解，附觀念提示。
- 每輪洗牌混合各題型；一般題以題幹、快速判斷以題幹及選項辨識近期重複，種子可重現。此單元開局使用 `BATTLE_PACING.quick`，五關兩種怪物都縮短蓄力，重擊型仍保留週期倍率；過關與再戰維持本局節奏。小數單元使用標準週期。傷害、血量、答對壓回與卡牌效果不變，未完成教室試玩校準。

## 視覺、操作與技術界線

- 整體採像素風。勇者是持劍、輪廓帥氣且攻擊動作明確的角色；敵人由低階到魔王逐關提升外觀與氣場。
- Pixi 負責低解析度戰場、角色、敵人、背景與攻擊特效，並以整數倍率放大維持像素感；使用專案內的本地 Pixi vendor。
- 在 UI 與平衡原型階段，Pixi 僅可使用簡單形狀、輪廓或文字佔位，不能先投入正式美術。角色、敵人、背景、特效、卡牌插圖與轉盤視覺均排在最後製作。
- React／DOM 承載題幹、四個答案按鈕、三選一卡牌、暫停、回顧與獎勵操作。這些內容不得只畫在 Canvas 上，才能支援文字閱讀、鍵盤與觸控。
- 中文正文以清晰可讀的字體為主；像素字型僅適合短標籤、數字或裝飾，不能降低題目閱讀性。
- 遵循既有主題系統，支援明／暗／系統模式、鍵盤 1～4 選答、觸控操作與減少動態偏好。攻擊、倒數、音效與特效皆須能安全暫停或降級。
- 計時器、事件監聽、Pixi ticker 與非同步工作在 React effect 清理時必須停止；過期回呼不得改寫新局狀態或重新啟動戰鬥。

## 原型平衡與驗證

- 執行 `pnpm balance:math-rpg` 可重算標準與快節奏的九種答題情境、五種選卡策略、32 條敵人路線，各路線共用 200 組種子；另以 `node --experimental-strip-types scripts/math-rpg-balance.mjs --all-builds` 檢查所有 81 種成長順序（另一批 100 組種子）。模擬直接呼叫遊戲 reducer，沒有第二套傷害公式；情境、作答速度與統計口徑見[模擬程式](../scripts/math-rpg-balance.mjs)。`pnpm test` 包含代表策略的平衡界線檢查。
- 模型以每題獨立正確率、答題時間均勻浮動 ±35%、閱讀回饋與選卡固定停留為假設；沒有模擬學生學習、疲勞與重複題熟悉效應。路線共用種子以利配對比較，不能當成全部獨立學生樣本。時間／題數／剩餘 HP 僅計首次成功局，失敗不混入通關時間；目前不模擬重試後通關率。
- 基準情境目標：正確率 80%、平均每題 16 秒，成功局平均約 9～12 分鐘；自動接題縮短回饋停留，熟練者提早結束，慢而準者可超過目標時間，不以硬性倒數迫使猜答。正確率較低的情境有明顯失敗機率，靠回滿 HP 再戰本關提供練習機會，不能宣稱人人一次通關。
- 同階迅擊／重擊的 HP 相同；重擊週期與原始傷害皆乘同一倍率，護甲也按該倍率抵銷，最後傷害四捨五入。平均輸出相等不保證每局等難，因此另比較整條路線通關率差距。
- 答題量先用 `Σ ceil(各關 enemyHp / 該關 attack)` 算出最低答對量，再除以正確率估算作答量；預估時間為 `作答量 ×（平均思考時間 + 回饋時間）+ 四次選卡時間`。這是未考慮死亡的期望值，成功局有存活偏差，須與模擬分開看。蓄力用有效戰鬥秒數累加、答對扣除 `retreat`；錯答反擊結算後歸零，重新計滿一個攻擊週期，詳見模型。
- 攻擊卡縮短所需答對數，護甲適合慢速／較多錯答，節奏卡在較快且準確時壓回較多蓄力；各策略仍需實際選卡行為驗證。回復不超過最大 HP，無永久戰力；失敗重試不重發已選卡。
- 回饋／成長時間計入遊玩時間，但不推進敵人蓄力；暫停與隱藏頁面不計時，返回頁面須手動繼續。作答量與時間包含本局再戰，回顧顯示再戰次數；重新整理不保存本局。
