## 放置原則

| 位置 | 唯一責任 |
| --- | --- |
| `docs/world/` | 暮光森林共同設定、角色身分與造型、原始美術與來源紀錄 |
| `docs/games/<遊戲>/` | 遊戲專屬玩法／教材／場景／美術；用連結引用世界觀 |
| `docs/project/` | 架構、待辦與必要的技術驗收證據 |
| `assets/images/` | 網站素材，按遊戲分類；工坊 `display/` 也是星燈小徑目前共用的載入位置 |
| `src/`、`assets/js/` | 現役程式；規則、數值與完整台詞以程式為準，不複製到多份文件 |
| `assets/uploads/` | 教學檔案，不當作角色母圖庫 |
| `assets/vendor/`、`node_modules/` | 本地引擎／安裝依賴，不歸入世界觀 |
| `dist/` | 可重建發布產物，不編輯、不當作原稿 |
| `.art-output/`、`tmp/` | 本機中間產物／試驗；正式參考先移入對應資料夾並建立來源索引 |

新增設定先更新既有權威文件；不要再建立第二份世界總覽或把角色介紹複製到各遊戲。原稿只存一份，圖鑑直接引用；改檔名或位置時同步修正 Markdown、製作腳本及程式引用。歷史過程查 Git，產圖提示與原稿關係留在美術來源紀錄。

數學勇者的原稿、參考圖與動畫仍在 [自身素材目錄](../assets/images/math-rpg/)，其格式由 [美術規格](games/math-rpg/art.md) 管理；沒有證據的素材不自行歸入暮光森林。動畫刻意重複的幀具有時序用途，不能只按檔案雜湊去重。
