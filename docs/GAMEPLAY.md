# GAMEPLAY · 各頁面的核心循環

九個頁面沒有共用的遊戲循環，這裡一個一個拆。

---

## 數學勇者 `pages/math-rpg.html`

**類型**：答題驅動的 RPG 戰鬥
**流程**：選年級 → 選題庫 → 玩法說明 → 六場連續戰鬥 → 通關 / 陣亡

**核心循環（一題＝一個回合）**

```
出題 → 30 秒內作答
  ├─ 答對 → 勇者衝刺攻擊 → 敵人扣血 → 連擊 +1
  └─ 答錯 / 超時 → 敵人攻擊 → 勇者扣血 → 連擊歸零
→ 結算狀態（流血扣血、迷霧倒數）
→ 敵人倒下？ → 三選一強化 → 下一關
```

**節奏設計**：基準 27 題打完全場（六隻怪 3/4/4/5/5/6 刀）。連擊一路不斷大約壓到 22 題。
數值細節見 [COMBAT.md](COMBAT.md)，強化卡見 [SKILLS.md](SKILLS.md)。

**題庫**：`assets/js/math-rpg-pools.js` 的 `QUESTION_POOLS = { 年級: { 題庫名: pool } }`。
一個 pool 可以是靜態題目陣列，**也可以是產生器函式**（`generateDivideQuestion` 會即時
出整數/小數除法題），`loadQuestion()` 用 `typeof activePool === 'function'` 分流。
五年級 9 個題庫、六年級 5 個，選單由 key 自動長出來。

## 極速博物館 `pages/turbo-museum.html`

**類型**：派工／排程策略，教的是**平行處理與關鍵路徑**（收尾點出阿姆達爾定律）
**流程**：五件古物依序修復，每件之間三選一升級 ＋ 隨機事件

**核心循環（一件古物＝一關）**

```
開場事件（第 1 關不觸發） → 看委託 → 派學者到亮起的工作卡
  → 工作完成 → 解鎖後續工序（🔗 相依）
  → 全部做完 → 依耗時給 ⭐ / ⭐⭐ / ⭐⭐⭐
→ 三選一升級 → 下一件
```

**難度往三個方向疊**（`LEVELS`）：修復線深度 `lines`（3→4→6→7→9 項工作）、
🔒 單人工作數量 `locks`（0→3）、各階段工時範圍。修復線固定 3 條、每項最多 3 人
＝ 最多 9 人同時有事做，**學者再多就會閒著，這正是要讓學生看見的平行極限**。

**星等門檻**（`TUNING`）＝ 電腦最佳派工的理想時間 × 倍率 ＋ 反應寬限。
拆成 `star3: 1.10` 倍率與 `grace: 1.5` 秒兩份，是因為只用倍率的話短關卡只多給 3.6 秒、
長關卡多給 10 秒，越後面反而越好拿三星。

## 字尾大分流 `pages/word-sort.html`

**類型**：英文構詞判斷，**專為教室觸控大電視設計**
**流程**：選年級題庫 → 12 題 → 結算

**核心循環**

```
卡片顯示「字根 + 空格」與中文意思（例：hope ___ 「一點希望都沒有的」）
  → 點下方大按鈕，或把卡片往左右甩
  → 正確字尾填進虛線格 → 格子滑過去黏住字根 → hopeless
  → 單字帶著索引掉進 ful[] 或 less[] 陣列
  → queue 的 [0] 往上飛走，後面全體遞補、索引重新編號
→ queue.length === 0 時結束（不是計時器歸零）
```

**設計要點**：出題方向是「給意思、猜字尾」而不是「給整個字、分類」——
後者的答案就寫在字尾上，變成純圖形比對而不是理解。

**抽題平衡**：`drawQueue()` 強制 -ful 與 -less 各半。題庫本身偏斜
（三四年級 11:20），純隨機抽的話一路按 -less 就有六成分數。

## 快問快答 `pages/quick-quiz.html`

**類型**：限時是非題
**流程**：設定每題秒數（1–60）與題數 → 作答 → 時間到自動公布 → 結算

最單純的一個。題庫是 `assets/js/quick-quiz.js` 開頭的靜態陣列，每題 `{ answer: true/false }`，
開始時洗牌抽出指定題數。進度環用 `RING_CIRC = 2π × 42` 畫。
`localStorage['tf-best']` 記最佳成績。

## 偵探事件簿 `pages/detective-*.html`

**類型**：點擊解謎 / 推理（Pixi.js v8 繪製）
**流程**：輸入解鎖碼 → 場景調查 → 解謎收集線索 → 指認犯人 → 結局

**核心循環**

```
場景裡點熱點 / 物件 → 看描述、拿物品、觸發謎題
  → 謎題解開 → 給線索 (clue) 或物品 (item)
  → 線索足夠 → 「🕵️ 指認犯人」解鎖
→ 指認 → 依誤判次數與旗標選出結局
```

**謎題型別**（各案自己宣告 `puzzle.type`）：

| 案件 | 型別 |
|---|---|
| 黃金貓頭鷹 | `caesar` 凱撒密碼、`safe` 數字保險箱、`lens` 濾鏡照畫、`deduce` 邏輯矩陣 |
| AI 展覽館 | `spotdiff` 找疑點、`wave` 波形解碼、`interrogate` 全息審訊 |

**存檔**：一組解鎖碼 = 一個小組的存檔位。進度寫進 Firestore 的 `unlockCodes` 文件，
老師在管理頁看得到各組進度。切換小組一律 `location.reload()`。

**做新案件前一定要先讀 [detective-authoring.md](detective-authoring.md)** ——
版面硬限制（可互動範圍只到 y=446、對話框 70px 天花板、物品欄 12 格）都在那裡。

## 班級 RPG `pages/class-rpg.html` → `pages/class-rpg-game.html`

**類型**：班級管理後台 ＋ Pixi 冒險世界
**現況**：管理端完整（Firebase Auth + Firestore 的班級／學生 CRUD），
**遊戲端還是基礎架構** —— 有角色動畫（走/跑、四方向）、樹木裝飾、一枚金幣，
還沒有實際的遊戲目標。

角色用 Mana Seed Character Base 素材，512×512 的 8×8 格（每格 64×64），
方向列順序是 **下、上、右、左**。跑步是走路循環的第 3、6 格換成第 6、7 欄。

## 課程頁（非遊戲）

### 水與酸鹼的微觀奧秘 `pages/water-acid-base.html`

簡報式教材，四個章節（水的解離 / pH 與 pOH / 14 平衡守則 / 水溶液性質），
搭一個**互動燒杯模擬**：全域狀態 `naohCount`、`hasIndicator`、`temperature`
驅動 DOM 與 SVG 的離子動畫，視覺一律由 `updateBeakerVisuals()` 重新推導。
動畫重播用 `void el.offsetWidth` 強制 reflow。

這是**唯一**使用共用 `assets/css/styles.css` 與 `assets/js/script.js` 的頁面。

### 神奇的墨水！原子筆的科學 `pages/magic-ink.html`

簡報式教材，兩大章（原子筆的世界 / 墨水的奧秘），內含三個小互動：
知識問答（`.quiz.trivia`）、毛細現象競賽、彩虹橋。
