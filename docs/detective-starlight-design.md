# 偵探遊戲：星燈小徑的錯位燈火

## 定位與範圍

第二款偵探遊戲的設計與實作依據。黃金貓頭鷹案維持現況；本案不沿用 AI 展覽館的案件內容。保留第一案「走進現場、查看物件、收集線索、解謎、比對說法、整理真相」的熟悉節奏，改以事件順序與路線重建作為新的推理核心。實際題目、時刻與解答以 [`starlight.js`](../assets/js/detective/cases/starlight.js) 和 [`starlight-rules.js`](../assets/js/detective/starlight-rules.js) 為準。

本案接續暮光森林世界觀。米洛仍是陪伴主角，可因夜間調查穿上便於行走的短斗篷、肩背記錄包並攜帶手提燈；臉部、髮型、身形等辨識特徵沿用現有設定。角色衣著依案件調整，不視為角色設定改動。可以新增居民，需有清楚的生活職責、個性及與既有居民的關係。

## 六項開工要點

### 一句話委託

諾爾發現星燈小徑的燈光指引圖樣偏離了原本路線，晚歸居民因此走錯岔路；米洛受託查明昨夜哪些燈被調整、為何改變方向，讓旅人和夜行小動物都能安心通行。

### 學習與推理目標

玩家從現場痕跡、居民證詞和燈具紀錄重建「誰在何時做了什麼」，再以事件先後與空間線索解釋錯誤路線如何形成。核心能力是觀察、時間順序、線索交叉比對和因果推理；結案前須能用多項獨立線索支持解釋，不能只靠單一證詞或猜人。

### 核心操作與規則

沿用第一案的點擊調查、可重讀線索、對話提示與場景移動。安排五個短謎題，由現場物件逐步帶出事件全貌；每題解答都提供下一步可用的事實，不以彼此無關的鎖碼填滿流程。

1. **重排巡燈紀錄**：把散落的巡查地點與時間記錄放回守燈亭的值勤板，找出燈光最後一次方向正常及最早確定偏移的時間，縮小燈罩被調整的時段。
2. **比對調整痕跡**：把燈罩卡榫上的新刮痕、遮光布纖維與沾有夜花花粉的工具套，配回小徑的三盞燈。解答指出哪些燈被動過；花粉只說明物件曾接近夜花，不單獨用來判定是誰做的。
3. **重現燈光方向**：在現場縮圖轉動第二、三盞燈的遮光罩，比較主路舊標記和夜花旁的弱光，重現昨夜偏向岔路的光痕。玩家確認改變方向的是遮光罩而非星燈本身。
4. **整理郵路與目擊時間**：將奧利的投遞印記、居民經過的地點和各自看到的燈色放到路線圖上。路程與時間可以解開表面上的證詞矛盾，並確認哪些人有機會看到燈罩改動。
5. **拼回事件順序**：把「夜蛾聚集、燈罩調整、旅人看見偏移光斑、郵件走錯岔路」等事件卡排成因果鏈，再指出仍需向哪位居民確認動機。這是證據整理，不是只靠猜人名的指認題。

### 劇情節奏與懸念設計

設計文件先列出完整真相供製作推理鏈使用；遊戲中的角色台詞和線索則依下列順序揭露，開場與前段不得直接說出「夜蛾照護員調整燈罩」或「為了保護夜蛾」。

| 段落 | 玩家目前知道的事 | 新線索／謎題帶來的變化 |
| --- | --- | --- |
| **起：不合理的歸途** | 星燈全都亮著，奧利卻把信送到「舊榛樹郵箱」；那條郵路早已停用。諾爾確認燈沒有熄滅，只是光照向不熟悉的方向。 | 玩家先調查信封、路標和星燈。疑問是「路沒有消失，為什麼大家都走錯了？」舊郵路印記也讓人猜想奧利是不是自行改了路線。 |
| **承：時間對不上** | 有人記得燈光照著路標，有人卻說那時光已偏向岔路；巡燈值勤板只記著巡查時間與地點，沒有記下每盞燈的角度。 | 謎題一重排值勤紀錄，確認最後正常及最早偏移的時間，圈出燈罩被調整的時段。謎題四稍後會解開目擊時間看似衝突的原因。 |
| **承：不是風吹歪的** | 燈罩卡榫有新刮痕，附近留有遮光布纖維和夜花花粉。痕跡像是有人動過，但仍不能由花粉或工具推斷是誰。 | 謎題二配對現場痕跡，將調查方向從天候故障轉為「有人調整了燈罩」。玩家會自然考慮是否有人故意把旅人引離道路。 |
| **轉：光不是指向藏匿處** | 調整後的燈光沒有照向屋舍或財物，反而落在路旁一小片夜花上；花叢裡有剛孵化的夜蛾。 | 謎題三重現燈罩方向，讓玩家看見光束原本被遮暗、並沿花叢上方形成一條低光帶。這表示調整可能是為了引導夜蛾避開強光，並非為了把人帶錯路。動機仍未證實。 |
| **轉：看似矛盾的證詞** | 奧利說自己沒有選擇舊郵路，另一位居民卻看見郵袋經過第三盞燈附近；舊路印記看起來像是他有意繞路。 | 謎題四整理投遞印記、實際步行距離和目擊時間，還原奧利是跟著偏移光線被帶上岔路，才經過第三盞燈。兩人都沒有說謊；舊印記是誤入舊路後留下的，不是他刻意改線。 |
| **合：誰做了、為什麼** | 玩家已知有人調整燈罩、調整發生的時間、受影響的路線，以及光線如何照顧夜蛾；還欠下最後的行動者和動機確認。 | 謎題五把行動者、時間、調整方式、光線結果與仍待確認的問題排成事件鏈。夜蛾照護員承認自己調整燈罩，說明原本只想讓夜蛾避開強光，沒有察覺低光帶會讓旅人把岔路看成回家方向。 |
| **收：一起修好路** | 事實已確認，沒有惡意犯人，但好意造成了真實的不便。 | 米洛、諾爾、奧利與照護員重新安排燈罩：保留夜蛾需要的柔暗區，在岔路加上不刺眼的地面路標。歸還的信送抵收件人，所有人都知道以後如何辨認新路線。 |

**完整真相（設計者用）**：夜蛾照護員芮雅為替剛孵化的夜蛾避開強光，調整了第二、三盞燈的遮光罩；她沒有察覺主路的舊地面標記因此變暗，弱光又沿岔路邊緣形成可誤認的低光帶。她的動機出於照顧而非惡意。調查先證明燈罩、光線與郵路的因果，再向芮雅確認動機。

開場文字方向：

> 「這盞燈明明亮著，為什麼信會走到舊榛樹那裡？」奧利把退回的信放到桌上。信封上的投遞印記，已經很久沒在正式郵路上出現了。
>
> 諾爾望向小徑：「昨晚沒有一盞燈熄掉。只是……光落下來的地方，和以前不一樣。」

轉折後的對話方向：

> 夜蛾照護員低頭看著收起來的遮光布：「我只想讓牠們不要被亮光嚇到。我不知道那道柔光會讓人看錯岔路。」
>
> 米洛把筆記本合上：「現在我們知道光去了哪裡。接下來，一起替旅人和夜蛾都留一條安全的路吧。」

無效操作不扣分、不耗盡線索，也不造成角色受罰。重排錯誤時可復原或再試；分層提示先提醒觀察方向，再協助比對線索，不直接代填答案。指認流程改為提出「事件解釋／需要再確認的線索」，避免把未證實猜測寫成對居民的定罪。

### 場景與介面草圖

主畫面是可探索的暮光森林夜間場所，不使用網頁卡片或表單拼成遊玩區。現有四個 Pixi 場景：星燈小徑的左右岔路分別通往夜花坡、石橋舊郵路，另可前往諾爾的守燈亭。兩條支路的夜蛾與郵路線索都須取得，才能整理最終事件。視覺沿用魔法工坊的靛紫暮色、暖木牌、羊皮紙與米洛立繪；文字依卷宗、線索卡和對話卷軸的安全區排版，避免碰到裝飾框。

- 星燈、燈罩、路標、郵件、夜花與石橋都是可調查物件；左右道路及回程木牌可直接點擊切換場景。
- 遮光布、燈罩、夜花札記和郵路拓片可拖入底部物品欄；相關謎題會要求先收納對應物件。米洛持筆記本記下線索；線索簿、時間排序和路線整理可再次查看。
- 提示由諾爾或同行角色在場景內對話提供；物件焦點、互動提示、進度和出口融入木牌、燈光及路標。
- Pixi 呈現主要可玩場景和物件操作，DOM 提供鍵盤、螢幕閱讀器及可存取的等效操作；觸控與鍵盤可完成核心操作，拖曳提供點選替代。手機版需重新配置場景，確保物件、文字與出口看得清楚且容易操作。
- 米洛服裝可改為夜巡裝束；諾爾沿用角色辨識與個性。新夜蛾照護員可有柔光面紗或收納遮光罩的工具包等職業辨識物，不用神祕化或把外觀當作可疑證據。

### 故事、彩蛋與系列連結

故事由「居民遇到實際困難」開始，以小徑重新照亮、旅人順利回家及照護員找到兼顧小動物的燈光方式收尾。諾爾的安靜細心可前後呼應：開場注意到某盞燈的光落低了，結尾則為怕黑的旅人保留一盞較柔和的夜燈。奧利可因送錯郵件提供時間線索；他的郵袋暗袋偶爾會收住一片迷路的風。

彩蛋藏在可選查看的生活細節和回訪對話，不參與必需答案、不誘導錯誤操作，也不要求重複失敗。例：米洛的記錄包裡夾著工坊的簡短補給清單；某封信被奧利提早送達，收信人因此多留了一盞燈。

本案可開啟「暮光森林偵探筆記」的系列連結：每宗案件結案後，筆記多一枚由委託居民留下的微光印記；印記逐步拼成一幅森林夜路圖，後續案件可在地圖上開啟新地點或回訪角色。這條長線只提供好奇與回訪理由，各案仍可獨立理解和結案；不要求改寫黃金貓頭鷹案，也不預設後續案件內容。

### 試錯與驗收方向

每個必要結論都要有至少兩處可回看且互相支持的線索；時間、光線與路線規則需在遊戲內講清楚。不同居民的證詞不能因緊張、沉默或外表而被當作有罪證據。完整線索不足時允許玩家提出暫定解釋並回去調查；重試與提示不處罰玩家。

規則與五題已在案件資料和題型模組中實作；時間界線是「最後確定正常」到「最早確定偏移」，不把首次錯投時間誤當偏移開始。每題可回看、重排或重新選擇，DOM 提供鍵盤與螢幕閱讀器的等效操作，包含收納小物件。班級與個人試玩仍需驗收實際時長、手機閱讀距離和推理難度。

## 時長與難度模擬

以下依四個場景、四件可收納小物與五個謎題估算，**不是實際遊玩測量**。學生邊讀邊討論、可重試操作的首玩目標約 **30–40 分鐘**；尚無班級實測數據，時間只作規劃基準。

| 本案流程 | 首玩估時 | 推理負荷 |
| --- | ---: | --- |
| 委託、角色與調查方式 | 2–3 分鐘 | 低：理解事件與場景互動 |
| 小徑探索、查看線索與初次訪談 | 4–5 分鐘 | 中：區分看見的痕跡和推論 |
| 左右支路探索與小物收納 | 4–6 分鐘 | 中：對照夜花坡和石橋留下的痕跡 |
| 重排巡燈紀錄 | 3–4 分鐘 | 中：依時間先後找出異常 |
| 比對燈罩調整痕跡 | 3–4 分鐘 | 中：多種痕跡配對，避免單線索定人 |
| 重現燈光方向 | 4–5 分鐘 | 中：操作物件並檢查空間因果 |
| 整理郵路與目擊時間 | 4–6 分鐘 | 中高：路程、時間與證詞交叉比對 |
| 拼回事件順序、確認動機 | 3–4 分鐘 | 中高：串起五段事件及證據來源 |
| 收尾與結果回應 | 2–3 分鐘 | 低：把推理連回居民需要 |
| **合計** | **約 30–40 分鐘** | **中等，後段有一段中高整合** |

五題各聚焦一項操作和一個發現；主要難度集中在郵路比對與最後因果排序。若實測時間常超過 40 分鐘，優先精簡重複文字或減少非必要點擊，保留關鍵推理步驟。

估時假設玩家會慢慢閱讀繁體中文、查看至少一次提示或回看線索，並可能由全班討論；快速點擊玩家和個別遊玩時間會不同。建議試玩時分別記錄個人及全班討論兩種情境，再調整謎題數量與對話長度。

## 後續驗收與系列規劃

- 偵探筆記微光印記的跨案呈現方式，以及是否要由系列第三案開始逐步揭露夜路圖。
- 班級試玩與個人遊玩的時長、文字可讀性及難度驗收結果。
