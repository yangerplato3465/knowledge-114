### T-01 · Pixi 特效層完全不理會 `prefers-reduced-motion`
**數學勇者**｜來源：[math-rpg-pixi.md](math-rpg-pixi.md) 第 9 節

CSS 那邊有完整的 reduced-motion 區塊（`.fx, .confetti { display: none }`，
`.picked` 也加進去了），**但 canvas 裡的粒子不受那個 media query 管**。

對前庭敏感的學生是真的會不舒服的問題。這是整層的既有缺口，
**要修就該一次處理所有效果**，不該只補其中一個。

字尾大分流的 `word-sort-fx.js` 有同樣的問題（新寫的，同一個模式）。

### T-06 · 字尾大分流的中文要不要加注音
**字尾大分流**｜2026-09-10 提出，尚未決定

目標年級是三、四年級，而紙本學習單的中文是帶注音的。
現在遊戲裡像「靜不下來、坐不住的」這種句子，字不難但有幾個中年級可能會卡。

技術上用 `<ruby>` 就能做，**只動 `word-sort-pools.js` 一個檔**。
但注音要逐字標，標完必須由老師驗過一遍才能上線。

### T-07 · 六隻怪都沒有攻擊圖
**數學勇者**｜來源：`math-rpg.js` 的 `PLAYER_LOOK` 註解

`atkFrames` 機制是通用的，但目前只有勇者有兩幀攻擊圖。

## 🔵 品質與維護

### T-08 · 肉眼手感沒有人驗收過
**數學勇者**｜來源：[math-rpg-pixi.md](math-rpg-pixi.md) 第 5、9 節

特效的驗證全部是數值斷言（粒子數、位移、回收歸零、零 console error）。
**數值對不等於看起來對。** 文件自己點名最可能要調的是弧高
`(1 + rand*2) * u` 和 26/14 這兩個粒子數。

### T-09 · `charge.webp` 是孤兒素材
**數學勇者**

`assets/images/math-rpg/charge.webp` 還在 repo 裡，但
[math-rpg-pixi.md](math-rpg-pixi.md) 第 0 節說它已經刪除（技能系統沒做）。
**檔案與文件不一致，要嘛刪檔要嘛更新文件。**

### T-11 · 兩份 vendor 的 Pixi 版本不同（8.20.1 UMD / 8.6.6 ESM）
**全站**

這是 D-28 刻意留下的：那次改動只做「拿掉網路依賴」，不動版本，
所以零行為變化、好回溯。

要不要統一到 8.20.1 是**獨立的一件事**，做的話要重測偵探兩案與班級 RPG。
不統一也完全能運作，只是 repo 裡有兩份（合計約 1.5 MB）。

### T-12 · 沒有任何自動化測試
**全站**

沒有 CI、沒有 lint、沒有測試套件，驗證一律手動。
目前的替代方案是用瀏覽器工具跑腳本化的過關驗證
（見 [TECH_ARCHITECTURE.md](TECH_ARCHITECTURE.md) 的「測試與驗證的實務」）。

這不見得要改 —— 對一個沒有建置流程的靜態站，引入測試框架的成本可能高於收益。
**列在這裡是為了讓它是個「決定」而不是「疏忽」。**
